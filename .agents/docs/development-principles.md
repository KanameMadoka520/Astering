# Astering 长期开发准则

本文件是后续开发的必读约定，由根目录 [AGENTS.md](../../AGENTS.md) 引用。它记录长期不变量，具体功能和发布记录继续放在各自文档中；不要把某次测试结果当成未来改动已经通过的证据。

## 品牌与兼容

产品与新发布统一使用 **Astering** 和 `aster` 版本标识，源码仓库为 `KanameMadoka520/Astering`；开篇说明基于 Vikunja 改造而来，并保留真实上游版权与许可证。真实域名、用户资料、密钥与存储兼容标识不能因更名盲目替换。历史发布展示可以迁移，但不重写原产物字节，也不声称历史包已重新构建；遵循[品牌迁移](../../docs/brand-migration.md)。

## 实现与性能

- 先查找并复用已有组件、查询模块、权限检查及后台执行机制，再决定是否新增抽象。优先消除重复实现和已证实的瓶颈；重写时迁移消费者并清理旧实现，不留下两套竞争的状态来源。
- 需要性能优化时，先用可重复场景测量网络请求、长任务、渲染或内存占用，再比较改动效果。不能只凭动画观感或一次总耗时声称性能提高；火焰图和调试附件应在隔离测试数据下采集。
- 长列表、流式内容、图片和附件按需处理。避免全量重复拉取、每个 token 扫描或复制整份历史、无界缓存、重复订阅、未释放的事件监听及 Blob URL。只在实际需要时引入新依赖或全局机制。
- 新接口使用 API v2，前端沿用生成 SDK 和集中查询层；修改接口后在本机生成、检查客户端。遵守 [API 设计](api.md)与[代码风格](code-style.md)，不手改生成文件。

- 主题由账户外观偏好决定，保留跟随系统、浅色、深色与星辰的兼容语义。主题 HTML 类由 App 统一应用，首路由认证就绪前不能用默认偏好覆盖启动缓存；缓存仅存外观选择，不持久化私人业务状态。星空装饰优先使用本地静态素材，不增加常驻动画循环或外站请求；内容表面、项目／星图自定义图片、强制颜色、打印和快速添加透明窗口都要实测。详见[星辰主题](../../docs/starlight-theme.md)。

## 异步操作与状态同步

- 删除确认及异步操作绑定操作开始时的资源、项目、路由、账户、API 地址及认证会话；切换目标、身份、会话或卸载后，旧结果不得关闭新弹窗、覆盖新草稿或跳转到旧页面。同一身份的正常 JWT 刷新不应误判为新登录。写入的身份检查还须覆盖 SDK 准备、鉴权拦截器等待后的实际发送边界，不能只丢弃迟到的回调；相关竞态应使用真实 SDK 和拦截器验证。
- 共享查询层负责服务端状态，表单草稿独立保留。普通修改与阿罗娜工具回执复用同一更新逻辑；局部更新相关列表、详情、分页总数和看板，不用整页刷新掩盖同步缺陷，也不因后台更新重置滚动和编辑状态。
- 删除资源时，要让仍挂载的详情观察者进入已删除状态，再清理相关缓存；仅 `removeQueries` 不保证打开的旧编辑器失效。禁止过期界面继续提交已删除资源。
- HTTP 快照与 SSE 必须在实际写入共享缓存的时刻协调先后顺序，覆盖首个 GET 尚未完成、提交确认、审核响应和微任务间隙的竞态。保留新消息与新事件，也允许后续合法 GET 更新；不要永久偏爱某个完成状态或仅凭客户端时间判断新旧。
- 临时竞态保护按查询客户端、账户、API 和会话隔离，只保留重叠请求期间必要的数据；请求结束、取消和客户端清理时释放，不给每个 token 留永久快照。

- 写入成功与后续读取分别表示：服务器已确认的操作不得因后台列表读取缓慢一直锁住确认，也不能把附加信息失败误报为任务未创建。批量部分成功时仅重试未完成项，保留已经确认的资源 ID 与父子关系，避免恢复整段原文造成重复创建。

## 缓存与私人资源

缓存策略以[浏览器缓存与私人图片](../../docs/browser-cache.md)为准，修改相关代码时必须同时核对该文档。

- 只有内容哈希命名、内容类型符合白名单的真实构建资源，以及受版本约束的 Workbox 文件可长期 `immutable`。固定地址资源、缺失文件返回的 HTML 和 API 不得误入此规则。
- HTML、固定地址图片、manifest 和 Service Worker 重新验证；私人图片使用 `private, no-cache`、验证器及保留原有维度的鉴权 `Vary`。必须先确认当前身份、权限、资源存在性和引用关系，再判断是否返回 304。撤权、删除或解绑后不得从离线缓存退回旧私人文件。
- 实时业务 JSON、配置、密钥、SSE、导出及非图片私人下载保持 `no-store`；不要改成持久缓存的业务状态来源。新的预览编码规则应更新验证器中的生成版本，保留原有 Range、流式和加密处理语义。
- Service Worker 使用本发布有限构建清单作为精确白名单，只在实际访问时缓存可长期公开缓存的哈希静态资源；安装和更新不批量预下载全站。使用统一 Router，HTML/API 网络规则先于静态匹配；不按任意 URL 的扩展名缓存外部或私人资源，不预下载整个网盘或聊天附件，只清理本应用、本作用域拥有的旧缓存。更新仍由用户确认，不能强制刷新丢失草稿。
- 弱网优化优先消除不必要的串行等待、重复请求和后台资源争抢。已建立且有效的同身份会话可后台刷新账户资料，首次认证、身份/API/认证会话变化、过期令牌及管理员权限校验仍保持必要等待。后台失败要捕获并退避；403 撤权不能继续展示私人缓存。加载新筛选可保留同一资源范围的旧结果，但必须明确标记等待、失败或离线，不能把旧列表或未加载误报为新结果或零条。动态模块加载失败保留当前页，通过正常路由重试，禁止自动整页刷新。
- 代理可能安全地改写响应：Cloudflare JavaScript Detection 注入的 HTML 可能没有 ETag。分别验证公网和源站，不为取得 HTML 304 关闭安全检测、放宽 WAF 或一概加 `no-transform`。
- HTTP 缓存由浏览器淘汰，不等于图片解码内存或固定预留磁盘。304 主要节省传输，不代表完全省去磁盘、数据库、解密或鉴权工作。

## 权限、隐私与模型执行

- 权限必须由服务端验证；普通账号、管理员、公开分享和 agent 工具均不能只靠前端隐藏按钮隔离。涉及权限的改动应验证有权限成功、无权限拒绝，以及适用的撤权和资源删除路径。
- 用户提供的 HTML、Markdown、外链、文件及模型输出均是非可信输入。保留已有转义、净化、文件访问与出站 SSRF 防护；不能为兼容一个服务商绕过安全拨号、重定向限制或当前用户权限。
- 密钥只在服务端按现有机制保存；读取接口及调试日志不回显。分享截图、导出调试信息和性能报告必须去除凭据及私人内容。备份恢复须同时保留数据库、文件及解密必需的 `service.secret`。
- 连接复制不改变功能默认值或提交其他卡片草稿。已保存密钥仅在同账户、已保存来源与相同认证目的地下由服务器复制到新连接，复制意图不持久化或返回；更换目的地需要重新填写密钥。
- 阿罗娜默认使用流式请求，遵循用户的协议、能力和运行设置。离开页面不会停止服务端任务；明确停止才终止执行。服务商提供的中间说明、工具步骤与错误记录应可靠保存，并遵循显示偏好；不编造模型没有返回的思考内容或用量。
- 阿罗娜运行槽按账号与会话隔离，不因一个会话生成或压缩而锁住整个账号。保留同会话历史写入互斥、业务事务和权限检查；后台观察者、停止与错误清理只作用于对应会话。账号删除必须取消全部会话，身份变化释放所有旧订阅；验证约定见[会话并发](../../docs/agent-concurrency.md)。
- 按需提供工具定义，分页或约束工具结果体量，按模型实际能力与配置维护上下文和压缩，避免把整份历史、附件或重复工具结果反复塞入请求。不得以任意很小的输出上限掩盖截断、压缩失败或循环故障。
- 阿罗娜内置工具按业务模块显式控制关闭、只读或读写，模块选择与外部 MCP 分开。关闭的模块不得进入发现结果或被直接、历史定义、恢复、审核、子代理等路径调用；服务端同时执行模块范围、全局工作方式、原有资源权限及审核校验。星图与个人笔记默认关闭；项目任务的旧配置保持兼容。设置只影响新请求，执行及等待审核期间沿用启动快照，界面明确提示需先停止再切换。增加模块必须补分类完整性测试和成功回执的局部状态同步，不能仅隐藏界面开关。个人笔记能力仅授权本人笔记，不继承管理员、团队或MCP权限；写入逐次审核、保留原始转录，删除另需明确许可与版本校验，不能用笔记工具开麦。具体契约见[工具模块范围](../../docs/agent-tool-modules.md)；弱网路径见[设计与验证](../../docs/weak-network-v49.md)。
- 工具发现回执必须保留完整结构，不能套用普通结果的截断预览。历史定义因版本变化失效时，在当前执行上下文中明确提示按需重新发现；恢复重试时先重建当前轮消息，再恢复仍符合当前目录和权限的工具。详见[工具加载与恢复](../../docs/agent-tool-loading.md)。
- 增加或扩展阿罗娜工具时，同时核对工具发现、参数及权限校验、审核快照、结果压缩、前端工具名称与审核字段，以及执行回执的共享缓存更新。不能只让后端执行成功，却让当前任务或看板保持旧状态；回执中的资源身份也必须验证。
- 项目内容历史采用命名保存点和按内容去重的压缩实体，不伪造上线前或未保存的历史。恢复前预览绑定当前hash及完整计划，原子保存恢复前状态并生成新版本，保留评论、真实打卡／工作记录及当前ACL。任务、历史文件引用及评论附件保护必须覆盖普通清理和账户删除；恢复后按ID映射完整核验内容，不能凭任务数量相同标记成功。统一项目、视图、任务锁序，跨项目/祖先范围按稳定顺序获取，等待后重查当前权限及归属。界面与阿罗娜复用恢复和局部更新，详见[项目内容历史](../../docs/project-versions.md)。
- 任务排序使用真实视图、相邻任务与顺序版本，在服务端原子分配位置；不能让模型猜浮点数或用逐条重编号破坏批次。保持读取只读、未选任务相对顺序、已加载分页和用户自己的排序偏好，详见[视图排序工具](../../docs/task-order-v46.md)。
- 外部 MCP 客户端与本站向外提供的 MCP 服务分开维护。连接按账户加密保存、独立开关，空的本轮选择表示不连接任何外站；不能在页面挂载时遍历全部目录、把所有远端 Schema 常驻塞入模型或自动继承给新会话。只在明确选中并需要时发现少量完整定义。远端注解不能自动授予只读、写入或删除权限；外部写入逐次审核，连接/密钥/定义变化使旧发现与审核失效，结果未知不得自动重放。保留 SSRF、凭据目的地约束、请求与结果限额及运行结束回收，不能用任意 stdio 命令代替安全的 HTTP 客户端。详见[外部 MCP 与聊天插图](../../docs/external-mcp-and-chat-images.md)。
- 当前附图的像素与可调用附件 ID 必须一起传给模型，并保持各协议一致；缺少 ID 或压缩后按需发现当前会话附件清单。清单按已发送及本轮可见范围分页，保留完整 ID 与分页边界，不回传存储凭据或图片字节，也不能被通用结果预览截断。
- 聊天图片写入任务时，会话身份与可见附件由运行器提供，不能信任模型参数。精确插图使用描述版本、块位置和图片指纹，保留共享任务权限与网盘引用规则；移除描述中的展示不等于删除聊天/网盘原件。按项目视图再按任务的统一锁序执行，不能与普通任务更新形成反向锁。
- 语音连接按实际协议适配，不能只替换模型名或服务商品牌。保留真正的端点、音频格式与采样率校验、密钥目的地隔离、取消和响应容量边界；区分上游流式传输与浏览器实时听写。服务商目录只声明已经核实并实现的能力，具体约定见[专用语音接入](../../docs/speech-and-routines-v41.md)。
- 语音输入采用点按开始与结束，触屏长按只是补充操作，键盘用户同样可操作。长按松手与取消须处理尚未完成的麦克风授权，迟到权限不得开麦；停止录音须等待最终音频事件，取消立即释放音轨。隐藏录音入口、切换会话或身份后不得继续录音或回填旧结果，不影响后台助手任务；详见[语音输入交互](../../docs/voice-input-v43.md)。
- 独立个人笔记的长听写与上述短语音分开维护：后台继续与常亮由用户明确选择后保存为本人账户偏好，后续仍须手动开始录音；每次开始捕获本次偏好，不因后台设置刷新改变已开始的行为。浏览器冻结、离页、身份/目标改变或设备暂停始终结束采集。常亮核对实际授权并释放迟到锁。PCM只短暂留在有界内存队列，不落音频文件；最终转录提交后才回执，正文版本与原始分句独立，私人笔记不因管理员或项目/MCP权限共享。不得把长听写选择扩散为短语音默认后台录制，详见[长时间实时听写与个人笔记](../../docs/voice-notes.md)。
- Android 客户端首次启动必须显示空的服务器地址，由用户手动填写并确认 HTTPS 站点；旧版硬编码地址不能在升级时自动迁移为用户选择。只为已选择的精确来源与主框架开放原生桥，网页 API 也须是该来源下的标准 API；外部页面、另一 API 目的地和迟到回调不得取得登录或录音能力。原生麦克风前台服务只允许当前可见界面明确开始，后台继续限本次授权录音；通知提供停止，不开机/强杀重启录音。网页登录与服务共用刷新协调器，切号/退出与迟到刷新不得恢复旧身份；更换服务器撤销旧会话、录音与同步，待同步文字按服务器和账户隔离，不能仅凭相同用户 ID 向另一站点发送。录音结束释放麦克风和锁，音频不落盘；不把录音前台服务当作已经实现了后台消息推送。签名私钥、密码和认证信息不进 Git/APK，维护稳定签名及递增版本。APK **只放 GitHub Release，不在业务网站托管或提供下载代理**，见[安卓客户端](../../docs/android-client.md)。
- 本设备多账号通过独立 HttpOnly 设备凭证关联已验证 SID，数据库仅存随机凭证摘要，不能保存密码或多份可恢复的刷新令牌。切换与刷新协调锁、跨标签页身份同步、旧账号视图和麦克风释放、撤销后不能复活，均是完整功能的组成部分。设备凭证不能扩大现有账号的业务权限；详见[设备账号切换](../../docs/account-switching.md)。
- 安卓离线识别运行库、小型 VAD 与许可证固定来源并校验后打入 APK；大型识别权重从 `.68` 起按需下载，不恢复全量内置。目录固定上游 revision、精确字节数与 SHA-256，不接受网页下发任意模型 URL；独立无凭据 HTTPS 传输只允许官方来源/CDN，断点需校验 Range，成品原子替换，未完成模型不可选。设备公共模型可跨账户复用，但录音用 lease 保护，切换/删除不能影响运行中的模型；可信 Android 数据根可规范化，模型内部路径仍拒绝符号链接。仅解码 JWT 不足以证明设备可访问某账号的本地转录，须保留服务器验证与认证代次栅栏。原始声音仍只在有界内存中处理；尚未同步的文字按账户加密暂存，容量满后停止而不自动淘汰，提供查看、复制、重试和显式清理。只有服务器幂等确认才移除待同步原件，不声称网页冷启动离线、断网在线 ASR 无损恢复或未实测的手机性能，详见[本地语音识别](../../docs/offline-asr.md)。
- 原始转录的真实 UTC 录音起点、相对录音偏移和笔记累计时间轴分别保存，不以接收时间伪造历史录音日期。自动入文是本次采集的可选快照，须原子幂等追加并保护未保存草稿。长篇整理保留原文，通过选定模型的上下文预算分片、分层合并和持久检查点完成；中断可恢复，截断不得标成完整结果，采用预览须显式确认当前文章版本，也不得因此默认开启项目或个人笔记工具权限。
- 显式协议终止应及时结束模型请求；Chat Completions 的 `finish_reason` 和 Gemini 的结束原因后仍可能有用量事件，不能提前丢弃。验证正常完成、断流、取消、重试及最后一段用量。
- 模型传输连接池按执行生命周期复用，子任务不关闭父任务的池，执行结束释放空闲连接；保留上下文取消和防护。不能为等待 HTTP EOF 挂起后台任务，也不能声称协议不允许时仍复用了 TCP 连接。

- 阿罗娜执行采用服务端生成、仅缩小权限的资源范围标记，覆盖内部 HTTP、直接数据库工具、审核续跑和子代理；实例管理员在其他管理入口的权限不能成为她读取／修改未共享内容的理由。标记不能持久化、由客户端伪造或改变原认证主体；增加执行路径时补真实管理员与共享／撤权回归。
- 只读站点用量使用独立显式 `ASTERING_USAGE_ADMIN_IDS` 授权并逐次重读活跃真人身份，不能继承 SMTP 或实例管理员权限，也不能接入阿罗娜工具目录。统计不解密会话／配置，不返回资源正文、邮件或密钥；统计归属不等于内容访问权。撤权或刷新失败隐藏旧私有快照，具体口径见[多账户边界](../../docs/multi-user-isolation.md)。
- 账户运维使用独立显式超级管理员授权；每次重查活跃真人与部署授权，拒绝机器人、API Token、分享及资源受限的助手身份。停用／凭据撤销必须同时使现存登录和名下机器人凭据失效，停止后台执行但保留数据；恢复不复活旧凭据。凭据签发在用户锁之后重查原会话／令牌，助手准入与取消还须覆盖“已鉴权、尚未注册运行”的窗口，不能只取消当时已注册的任务。保护自己和所有配置超级管理员，锁后校验目标状态与用户名，原子记录审计；不能把该角色当成跨账户业务权限，不能移走上游许可门控。
- 当前部署只有一个 Astering 应用进程，助手取消代次在进程内协调。扩展为多副本前，必须设计共享撤销代次与跨节点取消传播，并验证其他节点的已运行任务；不能把单进程取消测试当作多副本验收。

## 交互与可访问性

- 保留 SPA 导航和跨页面悬浮阿罗娜；内部链接按路由跳转，外部链接另开标签页并使用适当的 `rel`。操作完成后相关页面及时局部更新。
- 会话未读只在实际展示对应回复后确认，后台读取不能代替查看；确认绑定具体回复，迟到回执不能吞掉重试后的新回复，见[会话未读](../../docs/arona-unread.md)。浮窗调整仅改变外层布局，保留聊天实例和草稿；指针与键盘取消、视口约束和手机适配见[浮窗布局](../../docs/floating-arona-layout.md)。
- 看板“显示上级任务”只控制卡片关系提示，不删除或筛掉任务，不改变父子关系和子任务进度；按原有身份与视图范围保存有限偏好，见[看板显示](../../docs/kanban-display.md)。
- 日历复用真实任务与账户时区，开始/结束区间、独立截止和时间点保持不同语义，不从午夜猜全天或展开不存在的重复实例；打开任务弹窗不重置背景日历。全天使用明确的自然日起止与不包含结束日的边界，不能转成午夜时间戳；同时维护日历、项目时间线、公开忙闲、CalDAV、阿罗娜及详情编辑消费者。遵循[日历日期与权限规则](../../docs/calendar-v45.md)与[日历交互和全天日程](../../docs/calendar-v47.md)。
- 日历缩小时间轴只改变排布，不压缩字形或把标题与时间裁成半行；短事件保留可读高度，拥挤时提供完整的当天详情入口。验收检查真实文字行高与各层裁剪，不以元素存在、可见或有最小高度代替可读性；同月选日、跨月键盘焦点、空白时段点选／拖选、手机滚动和保存后的真实日期都要覆盖。
- 日历桌面工具栏优先横向排布，次要显示选项使用锚定浮层；手机沿用全站 768px 断点、单一视图入口及可展开筛选，显示设置使用现有底部面板。不要复制两套筛选 DOM 或状态，不在打开设置时把日历推离首屏；长项目名、安装提示、320–820px 过渡宽度和固定快捷栏都必须纳入真实浏览器验收。详见[工具栏首屏布局](../../docs/calendar-toolbar-v48.md)。
- 加载浮层按安全的资源类别与数字标识说明正在读取什么，区分等待、重试和文件接收；字节及速度来自真实采样，总量可信才显示百分比。压缩响应与 CORS 隐藏头不能误用传输长度。身份/API/会话变化、取消和异常必须清理；已有缓存的常规轮询与 SSE 不重复弹提示。详见[加载活动](../../docs/network-activity.md)。
- 进行中的提交、上传、生成或处理应有可理解的状态；可测量的上传显示进度，未知进度不伪造百分比。错误可定位、可恢复，避免静默无响应、重复 toast 或成功后又回滚成旧值。
- 重要操作保留合理确认、焦点和键盘行为；检查控件 SVG 居中、对齐、触摸目标、小屏溢出和长内容。动画应尊重减少动态效果偏好，并避免阻塞输入或制造整页跳动。
- 新增或调整的用户文案补齐通俗易懂的中文和英文；模型、权限及执行限制等专业设置提供简短解释和合适默认值。完整规则见[翻译约定](translations.md)。

- 异步完成导致重试／分页按钮移除时，只在焦点仍属于原操作且身份、资源与页面一致时移交到稳定入口；用户已经移走焦点时不得再抢回。

## 验证与证据

- 按风险选择验证范围，优先运行会暴露该问题的回归用例。修复的回归测试应能在未修复代码上失败；不写只复述实现或永远不会失败的断言。详细命令见[测试约定](testing.md)。
- 前端代码运行相应 lint 和强制完整 `pnpm typecheck`；样式改动加样式 lint。后端通过 Mage 执行对应 lint 和测试；共享数据库测试串行运行，避免多个 Mage 测试进程污染夹具。保存日志并检查真实退出码，不能让 `tee` 隐藏失败，不能反复重跑只为换一种输出过滤。
- 可见交互通过真实浏览器验证，并按影响范围检查桌面、小屏、键盘和中英文。状态持久化验证包括必要的重新加载或服务端读取；竞态测试使用真实查询生命周期，不以会隐藏问题的 composable mock 代替被测逻辑。
- 涉及缓存时，使用未启用 Playwright 请求拦截的 Chromium 上下文。`page.route`/`context.route` 等拦截会关闭 HTTP 缓存，不能用于证明命中。区分 CDP 实际网络 304、Fetch 合并后的 200、磁盘缓存和 Service Worker 命中。
- Service Worker 验证应检查真实激活、控制页面、实际 CacheStorage 内容和网络结果，不能仅在 bundle 中搜索字符串推断缓存范围。禁用 JavaScript 的生产探针不能依赖页面计时器或 RAF，恢复执行应使用同一 CDP 会话。
- 测试失败先定位，修复后重跑相关范围；保留失败记录和修复证据，不降低断言掩盖问题。声明“通过”必须对应实际执行结果；未覆盖项应明确说明。仅文档改动检查差异、链接和约定一致性即可，无需应用构建或生产登录。

## 数据保护与发布验收

- 阿罗娜短语音与长时笔记录音分开：短语音不写笔记或持久化音频，实时协议边录边传；先让最终转录可编辑／发送，再异步整理。停止必须排空尾帧并等待服务商完成确认，未确认字幕不能冒充成功，断流不自动重放；整理不得覆盖新草稿或回填其他会话，详见[语音输入](../../docs/voice-input-v43.md)。

- 长时听写须区分真实麦克风输入、采样、上传、上游字幕和事务保存。低电平不等于用户没说话，上游通用拒绝不等于密钥错误；保留安全的错误分类与诊断编号，不回显或记录原始服务商报错、录音和转录正文。音频上下文恢复与尾帧确认失败必须明确停止，不能假报正在录音或正常完成，详见[录音诊断](../../docs/voice-notes.md#录音诊断)。

- 测试数据与生产数据隔离。生产核验默认只读；确需登录时复用一个可辨认的维护会话，结束撤销该会话，保留用户自己的登录设备。不得为文档、读源码或每条测试重复创建登录。
- 部署前检查运行中任务，采用既有等待或安全停止机制，备份必要数据和秘密，记录源提交及当前镜像；部署和验收期间保留可用回退镜像。避免在用户仍有任务执行时直接重启。
- 数据基线比较要考虑并发用户写入。发现新增或变化时先核对时间、请求和持久化结果；不能为了让计数一致就恢复旧库、删除新记录，或把真实用户操作当成测试垃圾。
- 在本机检查、测试、编译和发布。源码、版本、镜像和 Release 产物应相互对应，上传后核对校验值；不新增或恢复 GitHub Actions，不隐式触发第三方自动发布。仅文档提交可以领先已部署版本，不因此重打旧标签或发布新二进制。
- 本机产物按用户 2026-11-06 的要求保留最新已验收版本。验收通过后清理旧应用镜像、旧本地发布包和重复升级快照，保留当前运行镜像及其本地发布包、最近一份经验证的完整升级前备份、独特配置备份、源码与 Git 历史、用户文件和必要审计记录。升级前备份不等于上线后新写入的备份，不能误报恢复时间点；远端 Release 不随本机清理删除。
- 每次发布验收结束检查 Go、BuildKit 等开发缓存及测试临时文件的体积。清理前确认没有相关构建、测试或文件引用，仅删除已确认可重建且无需保留的条目，记录实际磁盘前后差值；共享缓存不能默认视为 Astering 独占，清理共享编译缓存须说明下次重建的代价。保留最新构建的必要缓存，不无限保留历次快照；不能对整机、其他应用或数据卷执行无差别 prune。
- 附件的原件所有权、资源使用权限和展示节点分别管理；会话删除不级联删除已附加到任务的图片。回执只认可身份对齐的原生成功结果，失败／待审核／外部同名不得显示成功提示。引用加载或离线状态不能解释为零引用，详见[附件归属与保留](../../docs/attachment-retention.md)。
- 个人存储清理按当前账户及文件原件去重，回收不虚报释放量；预览绑定用户、目标、版本与动作，执行重查引用。不得删除共用原件、运行中会话或其他账户数据；详见[个人存储空间](../../docs/personal-storage.md)。

## 每次任务完成前

1. 对照用户本轮要求和上述不变量，检查是否有遗漏、遗留旧实现或未经解释的范围变化。
2. 核对验证结果、退出码、生成文件以及源码差异，不包含凭据、私人数据和无关修改。
3. 按根目录要求提交；需要部署时再完成数据、产物和运行状态验收，清理本次维护资源。
4. 说明实际改动、已验证范围和仍存在的限制。若形成新的长期约束，更新本文件及相关专题文档，确保后续 agent 无需找回旧对话。

### 站点防护与兼容

修改 1Panel／WAF 时遵守[本站防护维护](../../docs/1panel-waf.md)：先核对实际引擎与真实 IP 信任链、正常操作的命中证据，再改本站最小字段或规则。`allow` 可能结束后续检查，禁止为接口新增而默认放行整个 API／multipart。备份和回退绑定原字节，重放只用合成数据及无效凭据，不将生产配置或正文入库。
