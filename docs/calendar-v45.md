# 日历与日程（aster.45）

日常导航中的“日历”位于 `/calendar`。它与任务详情、看板和阿罗娜共用任务数据，不另建一份容易失去同步的活动记录。月视图用于总览，周/日时间轴用于精确排期，议程按日期列出安排；手机首次进入优先使用议程。

电脑时间轴允许 25%–250% 的行高缩放，周视图可选择 3、7 或 14 天。缩放改变时间轴布局，保留文字大小与可视时间锚点，不使用整页 CSS 缩放。日期、模式、项目、完成状态、重要事项和显示密度写入 URL，便于回到相同视图。打开任务详情使用现有路由弹窗，背景日历继续挂载，悬浮阿罗娜也不重建。

直接刷新任务弹窗地址时，共用弹窗路由先加载背景页面的懒加载组件，避免把组件导入 Promise 当成页面。手机全屏弹窗暂时隐藏背景时，时间轴只在重新可见后还原原滚动位置；普通缩放、调整窗口大小和局部数据更新不会套用这次还原。新建安排的身份绑定同时覆盖表单提交、SDK 准备、鉴权拦截器与实际发出请求的边界，正常同身份令牌刷新仍可继续。

## 日期的含义

- 实际设置的开始时间与结束时间组成安排区间，采用 `[开始, 结束)`；结束恰为次日午夜时，不多占次日。
- 单独的开始或结束时间显示为时间点，截止时间显示为独立的截止标记。没有另一端时不虚构持续时间，也不拿截止日期代替结束日期。
- 跨天安排按账户时区分段，保留原始时间；午夜时间不能证明用户希望“全天”。现有任务尚无全天/浮动日期标志，因此本版不猜测全天意图。
- 没有任何日期的任务继续保留在待办及项目视图，不塞进某一天。普通重复任务只显示已经保存的当前日期，不凭重复规则生成尚不存在的未来实例。
- 时间倒置的旧任务不绘制负时长区间，已有开始、结束、截止点仍可查看并进入原任务修正。

显示与新建均使用账户设置中的 IANA 时区。新建表单明确显示时区；夏令时跳过的本地时间不能保存，回拨时出现两次的时间需要明确选择 UTC 偏移量。日边界来自服务器，23/25 小时日按真实经过时间排列，避免只用墙上钟点相减产生负高度。

## 查询与权限

`GET /api/v2/tasks/calendar` 是只读薄投影，参数为 `from`、`to`（不包含结束日期）、`timezone`、`project_id`、`done`、`include_archived`、`page`、`per_page`。每次最多 62 个自然日；省略时区使用账户设置，省略项目或项目为 0 表示所有可访问项目，默认只显示未完成任务且不包含归档项目。

返回标准分页，以及 `timezone/from/to/days`。每个任务只出现一次，包含 ID、标题、项目标识/标题/颜色、任务颜色、优先级、完成状态及实际日期，不加载描述、附件、评论或关联树。权限在统计数量、排序及分页之前应用，项目筛选不授予额外权限。日边界独立于任务分页，前端仅汇总可见日期范围内的页。

JSON 使用 `private, no-store`；浏览器内的短期共享查询缓存按日期、时区和筛选隔离，未使用的日历查询很快回收，不在 Service Worker 或持久存储中另存私人日程。普通任务修改、创建、删除、项目变化和阿罗娜回执通过共享查询层刷新相关日历。首次 GET 尚未完成时收到修改，也会在快照落地后重新确认，避免初始旧响应使日历长期停留在旧状态。

## 阿罗娜工具

日程读取使用按需发现的 `list_calendar_events`，采用同一薄投影、分页与权限。创建、改期、清除日期、完成和删除复用 `create_task`、`update_task`、`bulk_update_tasks`、`delete_task`，不新增第二套写入协议。

工具日期使用带时区偏移量的 RFC3339 时间。未提供的字段保持不变；清除已有开始/结束/截止日期使用 `0001-01-01T00:00:00Z`。起止关系校验使用与现有值合并后的状态。只读模式、项目范围、删除开关和审核策略继续由服务器执行；读取到某项日程不等于获得写入权限。工具定义按需加载，不把整个日历或全年任务塞进每次模型输入。

## 后续维护与验收

继续复用生成 SDK、任务详情弹窗、共享查询更新和账户时区，不新增独立传输或任务状态仓库。改变日历数据字段时同时检查阿罗娜工具定义、发现与审核说明、中英文和缓存更新。

必要回归包括跨午夜、跨月、区间完全包住视口、相邻与重叠安排、仅截止、无日期、倒置时间、夏令时、非整小时偏移、无权限项目和分页。浏览器验证电脑及小屏布局、缩放不额外查询、日期快速切换、详情弹窗关闭后的状态、新建持久化与局部更新；测试使用隔离数据，不向生产写入演示活动。

视图与导航设计参考 [Google Calendar 官方视图及键盘交互说明](https://support.google.com/calendar/answer/6101541?hl=en)，移动端排布同时参考用户提供的 8 张截图。缩放范围和任务日期语义为本项目的实现选择。
