# 个人存储空间

设置 → 数据 → 存储空间（`/user/settings/storage`）用于清点和选择清理**当前账户**存储的文件与阿罗娜记录。它与只读的站点用量管理页面分开，不授予查看或删除其他账户内容的权限。

## 统计口径

- 原件按文件 ID 只计一次。任务附件、封面、星图和对话可以引用同一份网盘文件；引用不会再产生一份原件用量。
- 回收站原件仍占空间，是原件分类的一部分。移入回收站释放量为零。
- 派生预览、加密会话文件、旧版独立加密附件及受保护的 AI／MCP 设置分别统计。网盘中的聊天附件已经计入原件，不再次累加。
- 数字表示可归属的逻辑文件长度，不是服务器磁盘分区使用率，不包含数据库页、索引、WAL、备份、镜像和其他用户的数据。原件元数据与实际文件状态不一致或扫描不完整时，界面须明确提示，不能把未知解释为零。
- 清单分页加载，引用按需检查；不能为了“未引用”推荐而在每次打开页面时解密全部会话，或把尚未扫描的引用数显示为零。

## 清理边界

先选择具体条目，再由服务器预览当前状态和影响。确认凭证须绑定当前用户、资源、版本与动作，并有较短有效期。执行仍需重新检查所有权、版本及引用，不能把预览当成永久授权。批次逐项报告成功、阻止和失败，允许处理失败条目；不把部分成功显示为全部成功。

网盘原件复用现有回收站与永久删除机制。清理入口采取保守的引用保护，不自动解除任务、项目、星图或聊天中的引用。永久删除还需二次确认；存在引用、引用扫描失败、版本变化时保留文件。派生预览只能删除固定文件 ID 对应的可再生文件，不能接受客户端路径，也不能删除原件。

对话删除不可撤销，删除前须明确说明；运行或压缩中的会话不能删除。删除一份对话不删除网盘原件，也不删除其他会话／分支仍使用的旧版附件。受保护设置只供统计，不提供“一键清空密钥”。

## 身份与缓存

个人存储 API 仅对活跃的真人账户开放，每次在服务器重新验证身份；不向公开分享、机器人、API token 或 MCP 工具暴露清理能力。私人统计、清单和确认结果使用 `no-store`，浏览器仅保留现有账户范围内的短期内存查询。切换账户、API 地址或认证会话后，旧数据、选择和确认不可继续显示或提交。同账户正常 JWT 刷新不应清空操作。

清理后的网盘、引用资源与对话历史通过共享查询层失效或同步，无需整页刷新。界面须保持手机布局、键盘可达性、真实处理状态和中英文文案。

## 后续维护的必测项

所有权隔离、共享文件去重、预览后新增引用、旧版本／过期确认、重复执行、部分失败、会话忙碌、分支附件保留、符号链接拒绝、账户切换竞态，以及桌面和手机上的真实选择／预览／确认／重新读取持久状态。仅使用隔离测试数据，不能为验证清理功能删除生产用户内容。
