# 浮动阿罗娜的位置与大小

桌面右下角的阿罗娜窗口可以通过顶部专用拖动区域移动，通过四条边和四个角调整大小。“恢复默认布局”清除自定义位置和尺寸。操作仅改变外层布局，不能重建聊天组件、停止后台执行或丢失草稿。

窗口限制在当前可见视口内，避开站点顶部导航；切换窗口大小后重新约束显示范围。桌面首选大小保存在浏览器本地，仅包含四个布局数字，不包含会话内容或身份。小屏沿用手机面板，不启用挤占触控区域的桌面拖动、缩放边框；重新回到桌面可以继续使用原先布局。

指针操作每帧最多提交一次布局更新，结束后才持久化。Escape、指针取消、失去捕获、窗口失焦和视口变化均清理操作及事件监听；取消恢复操作前布局。卸载须释放动画帧与监听。

拖动和缩放控件支持键盘方向键，Shift 加大步长，并提供中英文名称和提示。Escape 在正在调整时先取消调整，不应同时关闭会话。恢复默认、最小化和关闭仍可用键盘操作；尊重减少动态效果偏好。

后续验证须覆盖真实 Teleport 中聊天实例与草稿保留、拖动、不同方向缩放、取消、重新加载的布局、视口缩小及手机无横向溢出。不能以会重建祖先的 Teleport 测试桩误判产品组件生命周期。
