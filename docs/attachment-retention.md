# 附件归属与保留

聊天负责保存交流，任务附件负责保存正式成果，个人网盘管理原件。删除一个使用位置不等于删除文件原件。

## 所有者与使用权限

上传原件归上传账户的个人网盘所有。聊天插图工具复用其 Drive 文件，为任务建立独立附件关系，描述使用任务附件地址。任务、聊天等引用同一文件时，原件只保存并统计一份。

能查看任务的人可以读取该任务附件；这不授予浏览上传者网盘或原会话的权限，也不转移文件所有者。审核应说明这种共享影响。

## 操作影响

| 操作 | 保留内容 |
| --- | --- |
| 删除会话 | 删除会话及模型上下文，解除对应聊天引用；保留网盘原件和任务附件。旧版独立加密附件只在没有其他会话引用时清理。 |
| 从任务正文移除图片 | 只删除对应展示节点，保留任务附件、封面和网盘原件。 |
| 删除任务附件 | 同一事务解除附件关系并清理描述、封面及评论中的对应图片；个人网盘原件保留。 |
| 网盘移入回收站 | 原件仍占空间；已有任务等引用仍可读取，不能新增使用。 |
| 网盘永久删除 | 所有使用位置解除引用后，才能按最新版本及二次确认删除；引用不明或扫描失败时保留。 |

账户删除不会让其他存活任务等引用的原件提前消失；它不隐式转移所有权。项目本身被删除时，相关任务引用按业务删除规则处理。

## 界面与回执

- 插入、移除、替换、移动、文字修改使用不同成功说明；任务链接只来自参数与任务结果中一致的安全整数 ID。
- 原生图片回执必须来自成功动作；失败、等待审核、结果未知、矛盾状态、外部 MCP 或不匹配身份不能显示成功提示。原始参数和结果继续按工具详情偏好展开。
- 手动修改任务正文后，保留提示只依据保存成功的返回结果以及仍存在的同一任务附件；未保存、保存失败、撤销或远程图片不触发。移除正文图片不会顺带删除附件。
- 会话删除与个人空间清理说明保留哪些文件；旧版独立附件规则按需展开，避免默认堆满手机界面。
- 网盘详情复用当前账户名称、使用位置链接及受限引用隐藏。归属规则默认收起；不能把缓存的空清单在后台核对、离线暂停或错误时当成“无人使用”。

## 验证边界

用隔离数据执行插图、删除原会话、独立任务下载、带引用回收和永久删除拒绝，核对原始字节、所有权与原件数量。浏览器覆盖桌面／小屏、英文／中文、操作回执、删除确认及引用查询竞态。不能为验证保护而删除真实用户内容。

本功能不是项目版本控制；未来项目历史必须另外持久保护历史文件引用，不能只保存旧 HTML 地址。
