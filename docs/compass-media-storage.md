# 星图图片与空间背景

星图正文的图片和空间背景复用网盘文件，不另建一份原图。上传、分类、回收和删除沿用网盘；正文只记录引用，不保存公开地址、临时 blob URL 或登录凭证。

## 存储与权限

正文规范形式为 `<img data-compass-image="文件编号" alt="说明" title="图注" width="宽" height="高">`。`src`、`srcset`、脚本属性、外部追踪图片被移除。正文最多引用 100 张不同图片，文字仍受 2 MiB 限制。图片支持 JPEG、PNG、GIF、WebP；挂载前核验 MIME、文件大小、解码尺寸和 5000 万像素上限。

`compass_media` 保存空间与图片的授权关系。第一次保存引用时，只能挂载保存者自己网盘中未回收、未彻底删除的文件。已经挂载的图片按空间当前权限访问，上传者退出团队不会破坏团队正在使用的内容；也不会因此让他保留空间访问权。另一个空间不自动继承授权。写作者可以预览本人尚未保存的草稿图片。

`compass_entry_media` 保留条目所有历史版本用过的图片，并标记当前正文是否仍在使用。删除正文中的图片不等于释放历史引用。回收站中的条目也保留引用；只有永久删除条目、删除空间或移除无其他引用的背景才解除不再需要的挂载，原文件仍留在网盘。

网盘使用位置区分正文、条目回收站、历史版本和空间背景。无权限时不显示条目标题或地址。文件回收需要确认；仍有上述引用时不能彻底删除。图片读取需登录和当前空间权限，缓存重新校验也检查权限，本版不开放独立 API token 图片访问范围。

## 事务和兼容性

图片索引、正文和版本快照在同一事务提交。空间锁后使用 current read，避免 MySQL REPEATABLE READ 在等待锁后仍看到旧引用。新挂载按稳定的文件编号顺序获取 Drive revision CAS，和回收／彻底删除操作串行化；不在文件锁后反向锁定所有空间。

空间背景使用 `background_file_id`、`background_focus_x/y` 和 `background_scrim`，与空间设置共用 revision 冲突检查。清空文件编号恢复主题背景。现有空间迁移后保持主题外观，不补造图片。现有表使用 partialSync 增列，保留原有列、索引与历史数据。

## 项目回顾的日期含义

时间范围需要真实开始日期和结束日期（没有结束日期时可以用截止日期）。只有截止日期的任务显示截止节点，不贡献工期或持续天数。完全无日期、只有孤立起点或结束点的任务不会被安到某一天。范围和截止节点独立判断，点击任何截止节点都能得到对应项目。

生命周期记录来自项目本身的完成、重新打开、归档等事件。任务进入 Done 不自动把项目标记完成；没有这类事件时，界面展示当前项目状态说明，不能虚构历史。年度时间回顾和生命周期记录解决不同的问题。
