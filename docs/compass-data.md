# 星图数据与权限

星图是私人的原则、理想、行动纲领、记忆与札记空间。名字、座右铭、序言、视觉主题由用户决定；没有预填的人生信条、伪造的历史或隐式 AI 写入。

## 私人与团队

- 默认私人空间，仅本人可见。实例管理员的项目管理权限不自动授予私人文字的访问权。
- 创建时可明确选一个自己管理的团队。当前团队成员可阅读、编写条目；团队管理员可修改空间设置和彻底删除回收站条目。
- 创建后不能更改空间的所属团队、所有者，避免不经确认把私人内容转成共享内容。团队移除成员后，该成员不能继续通过条目或历史接口读取。
- 星图不会自动成为公开主页，也不会自动进入阿罗娜上下文。API 访问令牌仍受各接口授权和同样的数据权限约束。

## 写入与保留

所有保存使用 `revision` 检查。相同版本的并发修改只能有一个成功，其余返回 409（20101）并要求处理冲突。无变化的保存不新增版本。历史恢复保留当前归档/回收站状态和置顶选择，只恢复正文及分类等写作内容；内容发生变化时生成新版本，而不修改旧版本。

条目可归档、移入回收站或恢复。只有已经在回收站内、且版本号仍匹配的条目，才可由空间管理员永久删除；同时删除其修订记录。回收站不会自动到期清空。删除账户会删除其私人空间；团队成员离开不会把团队文字变成私人所有，删除整个团队会删除该团队的星图空间。

每篇正文最多 2 MiB UTF-8，空间序言最多 64 KiB。允许基本 HTML 富文本、链接、列表与表格；脚本、嵌入、图片、表单、样式属性均被服务端清洗，前端还会独立清洗。正文为空合法，但标题不能为空。

## 可扩展结构

三个新表分别保存空间、当前条目、不可覆盖的保存版本：`compass_spaces`、`compass_entries`、`compass_revisions`。升级不改变原有项目、任务或索引。

列表返回摘要与元数据，不装载全部正文或历史；正文打开时按需获取。书库与修订记录分页，搜索支持文字、类型、分类、标签、归档/回收站状态。内容搜索是空间范围内的字面子串检索，百分号和下划线不作为通配符；当前没有引入外部搜索服务。分类与标签可自由输入，分类数量不与内置类型数绑定。

`content_bytes` 是当前正文的 UTF-8 字节数，不代表含修订记录、索引与备份的实际磁盘占用。完整数据库备份包含所有空间和修订记录；现有用户数据导出格式尚不作为星图的跨实例恢复接口。页面可导出当前文章 Markdown 或通过打印输出 PDF；这些单篇阅读产物不等同于完整数据库备份。

全部新路由位于 `/api/v2/compass`，前端通过生成 SDK 访问。错误码 20101 为版本冲突，20102 为资源不存在，20103 为内容/状态不合法。
