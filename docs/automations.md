# 阿罗娜自动化

侧栏的「自动化」把一段阿罗娜指令或简单提醒保存为后台计划。浏览器关闭后由服务器执行，结果保存在该账户自己的执行历史中；使用模型的执行还会生成独立会话，可以查看工具回执、用量和错误。这里是 Astering 内置功能，与 GitHub Actions 无关。

## 使用方式

新建空白计划，或从「早间概览」「每周回顾」「留一点时间回顾」开始。填写指令、时区和时间后保存；纯提醒直接发站内通知，不消耗模型 token。模型任务使用本人设置中已经保存的连接，可以选择项目上下文、允许写入的项目、工具模块及本次启用的 MCP 连接。

支持一次性、每天、工作日、每周指定多天、每月、每年及固定分钟间隔。界面显示计划时区和下一次执行时间，不跟随服务器时区猜测。月内不存在的日期、夏令时跳过的本地时间不会被移到另一天；夏令时重复小时每天最多执行一次，一次性计划可以明确选择第一次或第二次。暂停再恢复不会补跑暂停期间的任务。服务器停机期间错过的重复时间合并为一次，不排队补发全部历史提醒。

「立即运行」不改变原有计划。网络中断后在同一页面重试会复用请求编号；服务器先持久化执行收据，再开始工作。相同计划不重叠运行。暂停只影响之后的计划，停止当前模型执行请打开对应会话点「停止」。删除计划保留已经创建的会话及真实业务变更，不代表撤销它们。

每次执行使用准入时的指令和操作配置快照。之后编辑计划不会替换正在运行的指令。模型连接和 MCP 的有效配置、账号状态及资源权限在执行时重新验证；连接被删除或关闭会明确失败，不静默改用另一个连接。

## 审核与权限

普通会话和自动化共用四种操作审核策略。原来的智能审核、逐项审核和自动处理保持各自含义，增加「无人值守：在授权范围内直接执行」。新建自动化默认采用无人值守；早间概览和每周回顾模板仍为只读。

无人值守跳过人工点击，不扩大权限：全局读写方式、项目任务／笔记／星图模块、允许写入的项目、任务及笔记删除开关、当前项目角色、MCP 选择与连接策略仍然生效。精确图片放置、恢复项目保存点等操作仍先生成并验证提案、正文版本或计划哈希。人工审核字段只表示实际发生的人工审核，不把无人值守操作伪造成已经人工批准。

模型仍可以询问缺失信息；用户选择需要审核的策略或分段后停止时，自动化标为「需要处理」，打开会话回答或继续。无人值守不保证模型能完成任何不明确请求，也不自动重放结果未知的写入。

只有已登录的活跃真人账户可以保存或启动计划。API Token、分享链接、机器人及阿罗娜内部受限工具身份不能创建新的后台授权。每次模型执行签发与原账户绑定的短寿命服务会话，复用正常鉴权和资源权限；令牌仅在内存中使用，运行结束撤销，崩溃遗留凭据到期清理。超级管理员身份不授予自动化跨账户读取或修改能力。

## 运行、通知和存储

调度器每 15 秒检查一次到期计划，执行时间可能因负载、模型或网络稍有延后。当前单实例最多同时执行四个计划，每账户最多保存 100 个计划。每次总执行时间默认 60 分钟，可配置 1–1440 分钟；它独立于会话每段预算和已有的自动压缩／继续执行机制。达到总时限会停止对应会话并保留已确认操作。

后台总时限不延长部署者的会话撤销策略。服务会话的活跃时间在创建时记录；如果 `service.jwtttl` 比作业时限短，每小时的普通会话清理可能提前移除它，后续工具会拒绝，已完成更改保留。部署时应让该值覆盖最长作业和一分钟余量。`service.jwtttlshort` 不会把后台令牌截成普通短登录令牌时长。

每个计划保留最近 50 条执行摘要，完整结果会话单独保留和管理；摘要淘汰不会自动删除会话。模型自动化与普通聊天共用每账户 100 个会话的现有上限，归档会话也计入。达到上限时本次执行会明确报告「会话数量已达上限」，不会调用模型或擅自删除历史；请在设置的空间管理页删除不再需要的会话后重试。较早手动请求的防重标记不会随摘要淘汰而失效，超过其容量时需新建计划；不允许因为收据被裁剪而重新执行旧请求。重启后尚未确认完成的执行标为「已中断」，不自动续写或重放。

提醒及选择通知的执行写入站内通知，并沿用本人现有 Bark 设置。纯提醒属于 Bark 的提醒范围；模型结果摘要遵循全部通知范围。站内保存成功不等于手机已经收到，Bark、系统通知授权、网络和省电策略分别影响设备送达。通知只带安全的结果摘要，完整模型／工具内容留在私人会话；Bark 关闭预览时不发送提醒正文。

计划、配置快照和有限执行摘要按账户加密保存在现有 AI 数据目录，使用独立附加认证数据、进程内锁、文件锁和原子替换。设置的空间页单列其大小并链接管理入口，批量清理不删除计划；管理员用量只读取加密文件元数据，不解密指令。文件进入原有备份、账户删除和完整性检查范围，不增加数据库表。

调度执行由进程级文件租约独占。当前部署是一个应用进程；跨节点撤销与取消传播尚未验收，不把本方案描述为已支持多副本后台执行。后续上线必须在维护期间暂停新的调度准入并检查运行收据，不能只挡 HTTP 后假定所有后台工作都已结束。

## 参考

验证覆盖账户隔离、配置并发更新、幂等启动、重启未知结果、重复时间和夏令时、后台执行、真正的工具写入、通知隐私、手机布局及弱网／身份切换时的草稿保护。测试使用隔离数据库和本机合成模型服务，不向生产业务写入测试内容，也不依赖付费模型。
