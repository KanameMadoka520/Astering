# 网盘多选管理

入口为「我的网盘」`/drive` 顶部的「多选管理」。图片／附件选择器继续沿用原来的单文件选择操作，不混入文件管理按钮。

多选可以逐个勾选，或全选当前页的可操作文件（最多 60 项），并显示已选数量。它不声称选中了整个网盘。翻页、修改搜索或筛选、切换账号、API、认证会话、路由及离开页面都会丢弃旧选择。相同身份的正常令牌刷新保留选择。新页面尚在加载、占位列表、请求失败或单文件操作进行中时不能选择旧卡片。

普通文件支持批量置顶、取消置顶、设置分类、移入回收站；回收站支持批量恢复。分类是现有的扁平分类，不是目录，留空可清除分类。删除中的文件不参与全选，也不能批量恢复。永久删除继续使用各文件「详情与使用位置」中的原有入口，逐项检查引用并输入完整文件名二次确认。

每批先列出文件及可操作数量。批量回收逐项读取当前使用位置；已有引用或无法核实引用的文件会标记受保护并跳过，仍可查看详情。用户再次勾选确认后只回收已经核实无引用的文件；移入回收站不宣称释放空间。执行时每项始终使用 `confirm:false`，因此检查后新增的引用同样会被服务端保护。多选不能代替用户为引用中的文件进行单文件确认。

执行使用现有生成 SDK 和 `PATCH /api/v2/drive/files/{id}`，按选择时的 `file_id`、`revision` 和文件名、分类、置顶状态组成固定快照。置顶或分类只改变目标字段，其余字段照原样保留。没有新批量接口，也不猜版本号或自动覆盖其他窗口的修改。

每项请求串行执行，展示真实已处理数量与每项结果：已完成、已保护、未成功、结果不明。网络中断、服务器错误或无效响应不能被当作回滚成功，均不自动重放；成功项保留，重试需查看重新加载后的文件并重新选择确认。批次结束只统一刷新相关网盘查询和个人存储统计，不逐项拉取整个网盘。最后一页被清空时先保留结果窗口供用户查看，关闭后再纠正页码。

确认与实际 SDK 发送边界都绑定原账号、API、认证会话、路由及选择范围。身份或页面变化后，仍在 SDK 拦截器中等待的请求不能发出，已经发出的请求不会被解释成可回滚；后续文件不再发送，迟到结果不回填新页面。手机操作栏自动换行，勾选区域及批量操作提供触控尺寸，长文件名及使用位置可换行。复用原模态窗口的键盘、焦点与减少动态效果设置。

自定义模态内容须显式提供实色面板、正文颜色和手机两侧间距；通用 Modal 只绘制遮罩，不能让文字直接继承遮罩上的白色。验收需查看实际截图及面板背景，不能仅检查按钮能够点击。

验证由本机统一浏览器流程覆盖桌面、小屏、分页、分类和置顶的持久结果、回收恢复、引用保护、版本冲突、结果丢失与最后一页清空；请求竞态使用真实 QueryClient 和 SDK 拦截器定向测试。文档不代替每次发布的实际验证。
