## 运行与数据契约

模型的工作上下文与完整聊天审计分离：Steps/Actions/Operations/附件引用仍随会话持久保存。`result_ref` 限当前账户和当前会话，可用 `read_tool_result` 读取原始结果的 Unicode 字符分页。分页大小限制不影响模型输出 token 配置。列表只保留定位字段；任务详情将关联对象压缩为 ID、标题、状态；写入回执对已提交的长文本返回字符数和摘要校验，不重复回显整段描述。

`context_status` 的 tokens 是当前上下文估计或服务商实测校准值，绝不是累计计费用量。未声明容量时 context_window 为0；128000只是可修改的自动压缩策略阈值，不表示该模型最多128k。已知容量同时预留已配置输出空间。流式服务商未提供 token 增量时只显示实际收到的字符和耗时，不编造实时 token 速度。

自动压缩只在全部待调用工具已有结果时开始，期间可以停止。失败保留原上下文；成功原子保存检查点后替换工作上下文，并将最新请求与当前权限重新注入。已完成重建的上下文可在下一轮复用，分支只带分支点之前的状态。原始图片保留于附件系统，检查点保留引用；已读取的像素可移出工作上下文，通过 `view_attachment` 重新读取实际文件。未发送的草稿不进入模型的历史附件清单。

默认在每段轮数/操作次数/时间边界继续执行；`stop_at_segment_limit` 可恢复手动逐段模式。显式 token_budget 始终保留为软暂停条件，不因自动续跑而重置。八次完全相同的工具/参数/结果视为没有进展并停止。工具审核、提问、主动停止和未知写入结果均不会被自动续跑绕过。仅明确的上下文溢出允许在压缩后恢复一次；一般HTTP400、认证错误和响应流中断不盲目重放。

`enable_subagents` 默认关闭。开启后可发现 delegate_tasks，将1–4个独立只读任务并行执行；各自使用独立精简上下文和相同模型，继承账户权限、项目上下文、搜索策略，不能递归创建子任务。父任务等待全部子任务结束后汇总，子任务达到探索额度显示部分结果，不能假装完成。父停止传播给所有子任务；最终用量仅计入一次。父助手负责后续修改和最终完成判断。

## 附件与栏目

新聊天上传保存在个人网盘一次，会话保留引用；历史 AEAD 附件仍沿用加密读取。新的网盘文件使用网盘现有存储与授权方式（磁盘明文，具备网盘读取权限的 API token 可以读取文件，但不能读取私有会话标题）。`drive_chat_refs` 保守钉住引用，先钉后保存；移除草稿或删除会话只解除已确认失效的引用。彻底删除前扫描补查，读取/解密失败均拒绝删除，不能把未知当作无引用。分支独立保留引用。只支持现有单进程会话部署。

栏目工具通过 find_tools 按需发现，不把全部定义放入每次请求。提供视图查询、栏目查询/任务分页、新建、改名/WIP上限/排序、移动任务、设置默认/完成列和删除。沿用模型权限，写入范围、执行前版本校验、实际结果校验和审计回执；删除栏目始终审核，预览任务迁移目的列/数量/默认及完成列变更，不删除任务。手动栏目的工具不能修改按筛选自动生成的虚拟列；设置了明确项目写入范围时拒绝跨项目筛选看板的写操作。修复通用 Bucket.Delete 的默认/最左栏目删除迁移目标，确保目的列一定保留。
