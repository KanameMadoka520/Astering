# Android 通知与提醒

从 `2.7.1-aster.73` 起，原生客户端可以在网页关闭后接收后台提醒，并为已同步的个人事项安排本地通知。入口为头像菜单 → **客户端设置 → 通知与提醒**；页面无法打开时也可长按桌面图标进入客户端设置。首次安装默认关闭，由使用该手机的人开启并授予系统通知权限。APK 仍只发布到 [GitHub Release](https://github.com/KanameMadoka520/Astering/releases)，首次连接地址保持为空。

## 后台工作方式

客户端使用 Android WorkManager 批量同步提醒摘要，并用 AlarmManager 安排已经同步的时间。后台任务无需保持网页、屏幕或麦克风运行；收到通知、开机、升级应用和系统恢复后台任务都不会开始录音。实际录音仍遵循独立的可见启动和本次后台录音授权。

周期同步的最小间隔为 15 分钟，系统休眠、厂商省电、断网及后台配额可以继续推迟。已缓存的日程可以在有效期内本地提醒；刚刚在另一设备修改的内容，需要下一次成功同步才会更新。前台任务和通知状态发生变化时，网页会合并发出同步提示，由原生端重新向服务器读取授权摘要，不能直接用网页消息伪造提醒。真实系统推送（例如 FCM）没有在本版接入，不能称为实时推送。

默认使用普通系统闹铃；精确提醒需要用户单独授予 Android 特殊访问权限。拒绝或撤销精确权限时使用可用的普通提醒方式，并显示可能延迟的状态，不能偷偷改变系统设置。强制停止应用会影响系统安排，用户需要重新打开应用；不能承诺绕过 Android 或厂商限制。

依据：[持久后台任务](https://developer.android.com/reference/androidx/work/PeriodicWorkRequest)、[闹铃规范](https://developer.android.com/develop/background-work/services/alarms)、[Android 13 通知许可](https://developer.android.com/develop/ui/compose/notifications/notification-permission)。

## 个人事项与通知计数

个人事项包括**分配给我、我创建或有效关注的任务**，同时必须仍有对应项目访问权限。管理员身份不扩大这个范围；共享权限撤回、任务删除或完成、项目归档后，下一次成功同步会更新相应计划。订阅继承和最近一级静音沿用服务器原有规则。

服务器返回未来七天内的真实开始、截止时间及当前有效的明确提醒。无日期的任务不虚构时间，全天日期不自动解释成午夜活动。默认日期提醒和明确设置的提醒区分来源；只有无明确提醒的任务才使用默认日期提醒。日期提前量默认 15 分钟，可选 0、5、15、30 或 60 分钟。逾期只按真实截止日期判断，不把结束时间已经过去误称为逾期；开启日期提醒后，在成功同步时按账户时区每天最多发送一次逾期摘要，不另承诺固定送达时刻。

临期截止、近期安排、逾期和站内未读是不同统计；近期安排包括窗口内的开始或结束时间点以及覆盖该窗口的全天事项。一项任务可能同时符合不同条件，不能相加后声称是独立任务总数。首次开启先建立已有未读基线，不把历史收件箱全部重新响一遍。手机划掉通知不代表站内已读；站内已读仍通过网站正常操作更新。

桌面圆点来自有效的系统通知，客户端使用标准通知渠道和 `setNumber()` 提供未读计数。是否显示数字、显示在哪，以及系统设置关闭角标后的行为，由手机启动器决定；不接入厂商私有角标写入或伪造未读。录音常驻通知不计入消息角标。依据：[Android 通知角标](https://developer.android.com/develop/ui/views/notifications/badges)。

## 身份、隐私与有效期

开启时用当前已验证的人类会话签发**独立的 30 天通知授权**，只能 GET 通知摘要。它不能读取普通任务详情、原始通知正文、附件、模型密钥或 MCP 配置，不能编辑业务数据、调用工具或颁发新的授权。完整网页登录 JWT 与刷新凭据不会为了后台通知新增落盘保存。

这项授权独立于原网页登录 SID；远程结束某个网页设备会话不会同时撤销它。可以在 API 令牌设置中查看对应 Android 通知安装并撤销，管理员的账户停用、删除及全部凭据撤销也会生效。到期需要在已登录、可见的客户端设置中重新确认，后台不能自行续期。

每次安装使用随机安装 UUID，同一服务器与账户下重复授权只轮换该安装的通知令牌，不无限新增。每个账户最多授权 10 个有效通知安装；轮换不影响其他手机或普通 API 令牌。安装 UUID 只是标识，不是认证证明。

设备仅在不备份目录中用 Android Keystore 加密保存受限授权、有限提醒计划和去重记录。默认不显示私人预览，锁屏公共版本使用通用文字；打开预览也不扩大服务器授权。退出、换号、切换服务器或关闭通知，会立即撤销本机授权代次，取消对应工作、闹铃与消息。能够使用当前真人凭据时尽力撤销服务器令牌；离线关闭仍立即停止本机，服务器端授权可在令牌设置撤销或等待到期。

所有网络请求、异步授权、通知投递及点击都核对来源、用户和本机授权代次，迟到结果不能恢复退出前的计划。点击只接受任务、项目、自动化或站内通知等固定目标，再走当前账户的 SPA 路由和草稿保护；不接受任意跳转 URL，也不自动切换到另一个账户。

## 有界快照与故障处理

快照上限分别为 200 条任务日期、512 条提醒和 50 条未读通知元数据；全量计数与各部分完整性标记分开。截断结果不能把未返回的旧提醒当成已删除。缓存有效期最多 24 小时并受令牌到期约束，设备时钟变化不能延长授权；重启后先重新验证时间基准，不能把旧启动周期的时间当成现在。

网络失败保留已确认的有限缓存并按系统任务机制重试；联网发现 401／403、授权撤回或到期时停止对应提醒，不将失败显示成已同步。离线设备不能立即获知远程撤权，最多继续使用上述 24 小时内仍有效的快照。服务器 GET 不写任务、打卡或已读状态。新通知与本地提醒通过稳定身份与真实触发时刻去重，旧记录缺乏对应元数据时保守使用通用通知，不假装已经确定对应关系。

## 验证边界

服务器测试覆盖真实路由权限、同安装轮换、跨账户、撤销、项目 ACL 与订阅静音，以及快照完整性和正文最小化。原生测试覆盖凭据加密、归属、时间、去重、解析和网络限制；构建及 Android lint 在本机运行。网页原生桥的身份、导航和合并同步另有回归。

本机没有可用的 Android 模拟器或实机连接。通知许可弹窗、具体手机角标、Doze、重启及厂商后台限制仍需安装 APK 后验证，不能用桌面 Chromium 的手机尺寸宣称这些已经验收。安装说明及原生桥基础边界见[安卓客户端](android-client.md)。
