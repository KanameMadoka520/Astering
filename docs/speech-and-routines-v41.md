# 专用语音接入与周期任务（tcymc.41）

语音入口是 `/user/settings/ai` 的语音识别页。选择服务商卡片后，在独立弹窗中填写连接、模型和所需参数；保存只提交这张卡片，其他连接尚未保存的草稿继续保留。语音识别、口语文字整理和阿罗娜分别选择默认连接。

## 服务商与协议

| 服务商 | 适配方式 | 重要配置 |
| --- | --- | --- |
| 阿里百炼 | DashScope 任务 WebSocket；Qwen Realtime 会话 WebSocket；Fun 文件识别 HTTP | 默认使用标准北京接入地址，只需 Key 与模型；可选择其他地域或专属工作空间；语言、上下文、热词及词表均按模型能力提供 |
| 火山引擎 | 大模型流式识别的二进制压缩 WebSocket | 服务资源 ID；新凭据使用 API Key，旧应用凭据另填应用 ID |
| 小米 MiMo | 原生音频 Chat Completions，可解析 SSE | 模型与语言；消息仅发送该协议支持的音频内容 |
| OpenAI | Transcription Realtime WebSocket 或文件转写 | Realtime 使用 transcription intent、24 kHz 单声道 PCM；模型放在会话配置中 |
| ElevenLabs | Scribe Realtime WebSocket 或 Scribe 文件转写 | `xi-api-key` 认证；分段提交需要各自确认，不能把中途提交当整段结束 |
| Soniox | 原生识别 WebSocket | Bearer 认证，PCM 参数，最终词与临时词分开处理 |
| SenseVoice Small | 官方 FastAPI 自建识别接口 | 需要另行部署服务；不是浏览器本地推理，也不会自动安装模型运行环境 |

阿里推荐预设是 `qwen-audio-3.1-asr-flash-streaming`，使用 `run-task` / `task-started` / 音频帧 / `finish-task` / `task-finished` 的专用流程。`qwen3-asr-flash-realtime` 使用另一套 session 事件，两者不能靠替换模型名混用。Fun 文件识别也有独立的 HTTP 消息结构。

服务商目录由后端提供，记录模型 ID、协议、接入地址、采样率及实际支持的可选项。用户可以手动填写模型 ID；未知模型不会自动获得未经核实的参数能力。旧的 OpenAI 兼容、自定义及 Gemini 语音连接继续使用原来的协议，不会被改成某个品牌预设。

页面显示真正请求的端点（不带密钥）。测试使用当前卡片已保存的连接和选择的音频，返回识别文本、请求耗时以及可测得的音频时长、首字延迟。修改配置或换测试文件后，旧测试结果失效。这里的“流式协议”指服务器与上游的传输；对话输入仍是录完或选文件后识别，没有声称浏览器边录边出字。

### 阿里百炼简化接入（tcymc.42）

新增连接默认使用标准北京地址 `dashscope.aliyuncs.com`，填写对应地域的 API Key、选择模型即可保存。工作空间 ID 只在选择带 `{workspace_id}` 的专属地址时必填；已有连接不会自动切换地址。切换地域、地址或认证目的地时，需要重新填写密钥。模型开通情况及地域可用范围由服务商账户决定，不会在失败时偷偷换地址尝试。

词表 ID 是可选的识别增强功能，留空可以正常识别。需要使用已编译词表时，在百炼创建适用地域和模型的词表，再填写返回的 ID；填写并不会替用户创建资源。支持的模型也可以直接填写热词，不要求预先建立词表。专属工作空间 ID 或 API Host 可在百炼控制台的业务空间管理中获取。参考[官方地域与接入地址说明](https://help.aliyun.com/zh/model-studio/beijing-access-information)和[识别准确率与词表说明](https://help.aliyun.com/zh/model-studio/improve-asr-accuracy)。

DashScope 任务与 Qwen Realtime 连接另提供无需音频文件的连接测试：真实建立认证会话并确认服务端完成事件，再释放连接。该测试验证地址、认证和会话建立，不验证识别质量；选择音频后仍可运行识别测试。其他协议继续使用音频识别测试。服务商可能按其规则计费，不能把连接测试成功当作识别质量或所有模型权限已经验证。

## 录音、凭据与异常处理

浏览器录音通常是 WebM 或 M4A，不能把文件扩展名改成 PCM 就交给实时接口。前端会解码并重采样为该协议要求的单声道 16 位 WAV；服务器校验 WAV 块、实际格式及采样率后才提取 PCM。文件和录音继续受现有大小边界保护，转换失败提供可理解的提示。

每次录音拥有独立的麦克风轨道、录音器和清理函数。等待浏览器授权期间的重复点击不会创建另一段录音；切换账户、识别器、会话或离开页面后，迟到授权和结果不能影响新的目标。音频准备阶段也保留原始身份与 API 地址，提交前和返回后再次核对；取消会终止当前识别请求。

密钥按现有账户私有加密设置保存，读取接口不回显。修改上游地址、原生协议、工作空间或应用身份时，不能悄悄复用原目的地的已保存密钥。停用的识别器不能作为默认连接或通过测试接口继续调用。

适配器复用已有安全 HTTP 拨号、禁止重定向及取消机制，不为自建服务绕过 SSRF 防护。HTTP/握手错误不回显服务商可能夹带的密钥或录音内容。响应帧、累积识别文字、待确认条目和分句数量有独立边界；明确完成事件立即结束，取消和异常会回收上传协程与连接。

## 日历周期与额度

每日、每周、每月打卡保留同一张任务卡，可设置 IANA 时区、周期起点的小时和分钟、每周起始日或每月起日。月起日超过当月天数时使用当月最后一天。周期从服务器计算，不依赖浏览器日期；越过数个周期直接进入当前周期，不需要反复完成历史任务赶上今天。

每期可设置整数目标和单位，例如每周 3 次、本期 1800 毫升。进度接口设置本期的**绝对累计量**，同一个请求重试不会重复加量；达到目标标记本期完成，降低进度后恢复未达标。任务的 `done` 与普通重复日期不因此改变。需要表达小数时，可选更小的整数单位。

当前周期返回 `date`、`revision`、`period_start_at`、`next_reset_at`、`current_amount` 与 `completed_period`。客户端和工具使用服务器返回的周期日期与配置版本，陈旧周期或配置返回冲突，不能误写新周期。每次真实记录保留当时的时区、周期起止、目标、单位、进度和操作者；没有记录的周期不推测为完成。旧的每日打卡历史保留。

`task_routine_progress` 保存新周期记录；配置身份包含日历与目标信息，修改日/周/月规则或额度后不会把旧配置同一天的完成情况错当新配置已完成。暂停和停用保留历史。读取和写入继续遵循任务权限，项目归档后不能修改。

## 阿罗娜工具与提醒

日常和额度工具仍通过 `find_tools` 按需发现。配置写入前先读取当前配置，保留未要求修改的字段；工具写入继续受用户权限、项目范围、审核及状态冲突检查约束。

- 读取配置与历史：`get_task_routine`、`get_task_routine_history`。
- 设置周期和目标：`configure_task_routine`。
- 完成或撤销本期：`check_in_task_routine`。
- 设置本期累计量：`set_task_routine_progress`，用户说“再加”时先读取当前量，再计算绝对累计量。
- 普通循环任务可以按看板视图配置回到默认栏目、保留完成前栏目或返回指定栏目；指定目标必须属于同一视图并且不是完成栏目。
- 任务提醒工具支持已有的截止、开始、结束时间相对提醒，负秒数表示提前。新增 `routine_period_end` 表示本期结束的相对提醒，本期达标后不再提醒，下一期按日历继续适用。

周期提醒复用现有提醒调度与通知渠道，不新增逐任务定时器。操作审核快照包含相对锚点和偏移，避免两个此刻时间相同、下期语义不同的提醒被错误当成同一操作。

修改周期前会校验已有提醒，防止把每周提前两天的提醒带到每日任务而静默失效。允许的偏移须适用于短月及已知的夏令时短周期；不合适时明确提示先调整或移除提醒，不自动改写用户的设置。日期读取只投影当前周期，不改写原提醒。CalDAV 不导出这类没有标准 VTODO 锚点的周期条件提醒，避免其他日历生成错误或重复通知。

## 验证边界

协议回归使用本机 TLS HTTP/WebSocket 服务验证真实请求结构、音频帧与事件顺序，并覆盖部分结果修订、重复 final、提前结束、取消、响应容量和凭据隐私。浏览器验证使用隔离数据库，配置保存及重载通过真实应用 API；语音服务的付费调用使用模拟响应。它们不等于已验证用户在各云厂商账户中的密钥、模型开通状态、地域额度或真实识别质量。
