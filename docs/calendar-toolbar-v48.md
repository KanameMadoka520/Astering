# 日历工具栏与首屏布局（tcymc.48）

桌面日历的日期、视图、项目筛选和新建入口集中在顶部。宽屏采用两行布局，较窄桌面允许有序换行；不通过缩小字形、压缩按钮文字或隐藏日期语义换取空间。全站导航已经显示“日历”，页面保留可访问的标题，不重复占用一个大标题及说明区。

## 桌面与手机

- 桌面首行显示日期范围、账户时区、视图和任务入口，次行放日期导航、项目筛选、完成状态、优先级及加载状态。两行独立分配空间，避免首行操作列的宽度挤压次行筛选。
- 显示设置复用共享 `Popup`：桌面锚定浮层，打开、修改或关闭时不推移下方日历；手机复用底部面板，内容可滚动。
- 手机沿用全站的 768px 断点，首次进入默认议程。保留一个视图选择器，筛选图标并入日期导航；已启用的额外筛选以数量标识，默认隐藏已完成不计数。展开后操作原有的一份筛选控件和统计；收起时保留屏幕阅读器的加载状态播报。
- 手机顶部、底部快捷按钮保留至少 44px 触控目标；底部“今天”和“新建安排”避让悬浮阿罗娜及安全区域。时间轴的列密度和全天新增入口使用相同断点。
- 项目名过长时在卡片内省略展示，完整内容仍可通过任务查看；议程列表的网格列使用 `minmax(0, 1fr)`，不会因长名称撑宽整个页面。

时间轴根据视口、全站页头、页面间距及实际工具栏高度分配滚动区域。工具栏使用一个组件作用域内的 `ResizeObserver`，只影响下方区域高度，不监听滚动、不重新查询任务，也不形成父子尺寸反馈。空白时段操作说明位于时间轴之后，不再单独挤占顶部。

## 状态及维护边界

日期、月份锚点、选中日、视图、项目、筛选、农历与缩放仍由既有 URL query 管理，支持链接与重新加载。展开筛选和打开显示面板只是展示状态；不要复制第二套筛选 DOM、查询或草稿。任务弹窗、同月选日、缩放保持可见时间及本地查询缓存沿用原实现。

本轮没有新增依赖、后端接口或数据库迁移，不改写真实任务、模型连接或账户设置。日期语义仍以[全天日程及交互规则](calendar-v47.md)为准。
