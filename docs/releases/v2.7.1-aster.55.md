# v2.7.1-aster.55

本版本增加个人存储空间清点与选择清理，补全阿罗娜未读状态、桌面浮窗布局控制，并允许收起看板卡片里的上级关系提示。

- 设置 → 数据 → 存储空间：按当前账户去重统计原件、预览、回收站、会话与受保护设置，分页筛选文件和会话，查看使用位置，先预览影响再清理。永久删除需额外确认；执行时再次检查引用、版本和归属。回收站仍占空间，不能虚报已释放；统计不包含数据库、备份和其他账户数据。
- 阿罗娜会话列表：后台新回复保留“未读”，实际查看后再确认。按具体回复收据处理重试与迟到响应，后台读取不自动清除未读，升级不批量标记旧历史。
- 桌面浮动阿罗娜：顶部拖动、边角缩放、键盘调整和一键恢复默认，记住布局并约束视口；调整时保留草稿、聊天实例和后台执行。手机沿用独立适配。
- 看板：增加“显示上级任务”开关，隐藏卡片关系提示以减少高度，记住每个看板的选择；任务卡片、关系和子任务进度保留。

个人存储与已读确认均为活跃真人账户的私有 API，不开放为模型工具。无新增数据库迁移；升级保留既有账户、共享权限、SMTP／AI／MCP 密钥及注册设置，不会自动清理用户文件或对话。

维护契约见[个人存储空间](../personal-storage.md)、[会话未读](../arona-unread.md)、[浮窗布局](../floating-arona-layout.md)和[看板显示](../kanban-display.md)。构建与发布继续在本机执行，GitHub Actions 保持关闭。

本机验证：强制完整 TypeScript 检查通过；Go lint 0 问题，前端与样式 lint 无错误；相关前端单元测试 82 项通过，另有 1 项可选性能基准跳过；Mage 后端过滤测试及真实 API 权限／清理测试通过。真实 Chromium 分批验证 14 个不同场景，覆盖看板关系开关与重载、阿罗娜后台未读／查看确认、浮窗拖动缩放与草稿保留、存储回收及永久删除、引用阻止清理，以及 320px 中文布局。所有写入测试使用隔离数据。
