# v2.7.1-aster.67

本版改善 Astering Android 客户端的可视空间与设置入口。基于 Vikunja 改造；本机完成检查、编译、签名及手工发布，不使用 GitHub Actions。

- 正常页面移除原生服务器地址与「客户端设置」整行，把高度交给网页正文；网页原有导航继续保留。
- 登录后从头像账户菜单打开「客户端设置」，查看当前服务器、Android 版本，更换服务器、检查更新或处理旧版待同步文字。手机阿罗娜页面沿用导航抽屉中的账户菜单，不增加常驻按钮栏。
- 网页通过原生能力握手显示入口，普通浏览器与不支持的旧客户端不出现无效菜单。打开设置不会刷新网页或丢弃未发送输入；关闭后继续当前页面。
- 页面加载失败时提供原生设置按钮；连接旧版网站或尚未登录时，也可在系统桌面长按 Astering 图标 →「客户端设置」。快捷方式复用现有主页面，不用系统默认清任务行为销毁草稿。
- 横竖屏、窗口尺寸及键盘配置变化保留当前 WebView，只重新排布内容；系统语言、主题切换与进程死亡仍可能触发正常重建，不承诺恢复未保存的进程内输入。

设置入口只允许可信来源的主页面打开原生菜单，不携带凭据或直接执行菜单中的动作。更换服务器、安装更新及旧文字恢复沿用各自明确确认；打开设置、快捷方式或恢复页面都不会自动开麦。

Android 版本为 `2.7.1-aster.67`、版本码 `67`。稳定应用 ID 与正式签名保持一致，可覆盖升级；首次配置的服务器地址仍为空，必须手动填写。APK **仅发布在本仓库 GitHub Release**，不在业务网站提供安装包。

本版没有 Go 业务、API 或数据库迁移变更。服务端更新仅提供头像菜单与能力兼容代码；部署核对完整备份、隔离恢复及两次迁移无变化证明，保留现有用户、权限、会话和私人资料。

安装、原生桥与能力边界见 [安卓客户端](../android-client.md)。本机浏览器验证不能替代真机的桌面长按、原生弹窗、旋转、麦克风硬件及厂商后台策略验收。

本机验收：前端完整 lint 与类型检查通过；103 项相关单元测试及补充异步边界回归通过；原有 7 项导航场景与新增 4 项客户端设置场景通过浏览器端到端验证，包含 390px 中文手机与桌面英文、旧客户端兼容，以及打开设置时同一输入框和未发送草稿保持。Android 24 项 JVM 测试、正式资源编译、lint（0 错误）和签名构建通过。APK 验证应用标识、版本、稳定签名、16 KiB 对齐及内置模型、运行库和许可；未连接真机，原生对话框与桌面长按仍需在实际设备验收。
