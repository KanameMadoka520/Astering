# Astering v2.7.1-aster.62

Astering 新增个人笔记与实时语音记录，让随手记下的文字、谈话中的要点和后续整理保存在同一个地方。

- **个人笔记**：独立保存、编辑、搜索和置顶笔记，支持 Markdown 整理。编辑内容与语音识别原文分别保留，可以整理笔记而不覆盖原始文字记录。
- **实时语音记录**：使用已配置的阿里云百炼流式语音连接，边说边显示识别结果，最终句子提交成功后纳入笔记记录。支持 DashScope 流式 ASR 与 Qwen ASR Realtime；不支持的协议会明确提示。
- **适合较长记录**：录音过程中按服务商会话时限轮转连接，继续同一篇笔记的时间轴。界面显示录音状态、已发送音频量、发送速度、待发送缓冲和已保存段数；中断与保存失败会明确提示。
- **交给阿罗娜整理**：勾选原始分句或选择部分文字，预览整理／项目安排要求，再带入阿罗娜草稿；不自动发送，不覆盖现有草稿，也不扩大她的项目操作权限。选中的原文也可以先加入笔记正文编辑。
- **编辑保护**：笔记使用版本校验，遇到其他页面已修改的内容时提示冲突，避免直接覆盖。手机与电脑均提供录音控制及笔记编辑入口。
- **个人数据隔离**：笔记仅供所属个人账户访问。管理员、团队成员或机器人身份不会因此自动获得笔记权限，也不向阿罗娜的工具调用提供笔记读写入口。

录音只用于实时识别，**Astering 不保存原始音频，也不会把录音作为网盘或会话附件存储**。浏览器向本站发送短 PCM 帧，由服务器使用当前账户保存的语音连接转发给所选服务商；服务商如何处理音频以其政策为准。

默认以前台录音为准；录音前可明确选择“允许在后台继续”或“尽量保持屏幕常亮”。后台选项只在浏览器实际支持时继续，离开笔记页、系统冻结、音轨中断或网络长时间阻塞仍会停止采集或提示暂停，并尝试提交已经收到的尾部识别结果。此功能依赖浏览器的麦克风与 AudioWorklet 支持，不承诺锁屏或操作系统挂起后的后台持续录音。

最终分句通过轻量回执更新，不因每句话重新下载整篇文章。原始记录默认直接展示最新 100 段，也可从头分页；阅读或选中文字会暂停视图跟随，录音与保存继续，点击“最新记录”清空选择后恢复跟随，避免长录音导致阅读位置跳动或页面和内存无限增长。设置中的个人空间单独显示笔记数量与文字逻辑大小；它不等于数据库实际占用的磁盘块。

升级包含 `aster_notes` 与 `aster_note_segments` 两张新增表。已有项目、任务、附件与账户表不需要修改；升级前仍应保留数据库和文件备份。本版本使用本地构建与手动 Release，不需要 GitHub Actions。
