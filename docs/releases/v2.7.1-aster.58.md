# v2.7.1-aster.58

本版本把聊天图片、任务附件与个人网盘之间的归属和删除影响说明清楚，并加强引用核对期间的删除按钮状态。

- 阿罗娜插图成功后说明任务图片独立于原会话保留，并提供内部任务链接；移除、替换、移动、修改文字分别显示准确回执。只有身份一致的原生成功结果才显示，失败、待审核、结果未知及外部同名工具不会被误认为已完成。
- 插图审核说明任务权限共享的范围，明确不共享整个会话或个人网盘，也不转移文件所有权。
- 手动编辑任务描述并保存成功后，若原有任务附件图片已从正文移除而附件仍保留，会说明正文与附件的区别；草稿、撤销、保存失败及外部图片不触发此提示。
- 删除会话及个人存储清理明确保留网盘原件、已附加到任务的图片与已经发生的任务修改；旧版独立聊天附件的清理规则按需展开。
- 网盘文件详情显示当前账户所有者、原件复用说明、使用位置及默认折叠的归属规则。只从正文移除图片不等于删除任务附件；已有引用也不会因网盘回收而失效。
- 缓存中空引用清单在后台核对、离线暂停或错误时，不显示为已确认无人使用，也不能据此确认删除。引用最终由服务端重新校验。
- 修复个人空间清理的复选框显示与选择清单不一致的问题；鼠标和键盘使用原生勾选状态，受保护项目、处理中状态和数量上限仍阻止选择。

中英文文案同步更新；桌面与手机复用现有组件、确认和局部状态更新。后端业务逻辑、数据库结构、文件存储格式、权限、注册设置及固定品牌资源不变，原件继续只保存一份。项目历史版本是仍在设计的独立功能。

- 31 项相关浏览器用例通过：26 项对话、网盘、附件封面及任务阶段检查，加上修复后复验的 5 项空间清理用例；最后的完整保留流程另行通过。覆盖桌面与 320／360／390px 小屏，真实文件与原生键盘勾选；未声称实体手机验收。
