# v2.7.1-aster.65

本版本扩展设备账号切换、弱网实时听写、安卓本地识别和可恢复的长篇笔记整理。基于 Vikunja v2.7.1 改造，保留上游来源与许可；全部检查、编译和产物发布在维护者本机完成，不启用 GitHub Actions。

- **设备账号切换**：最多五个已验证登录，支持添加、切换、移除和全部退出；随机 HttpOnly 设备凭证仅保存摘要，复用可撤销 SID，不存密码或多份刷新令牌。切号关闭旧身份录音、私人视图和订阅，并同步同浏览器其他标签页。
- **弱网听写**：在线识别有界退避重连，继续未发送音频，浏览器最多三十秒内存缓冲。已经交付旧连接却未收到确认的声音不自动重放，可能缺失时明确提示；权限或存储错误不会无限重试。
- **安卓内置本地 ASR**：sherpa-onnx 2.0.1、SenseVoiceSmall int8 2024-07-17 与 Silero VAD，模型资产约 229 MiB，CPU 推理、ARM64、支持 Android 8+，自动识别中英文，不随界面语言强制单一语言。原声音仅在有限内存中处理；文字按账户使用 Android Keystore AES-GCM 暂存，联网后固定 UUID 幂等同步，成功回执才移除本机原件。提供查看、分页复制、重试和明确确认后清理。
- **真实录音时间**：UTC 开麦起点、录音内采样偏移与笔记累计时间轴分别记录；可选择 IANA 时区和默认自动追加正文。旧转录没有真实日期时明确标记未知，正文空间不足不丢弃原始分句。
- **阿罗娜长文整理**：文章或原始转录按选定模型的上下文预算分片、分层合并，保留检查点，离页继续、取消和失败后恢复。先看预览，再明确追加或替换，核对正文版本并保护未保存草稿，不自动开放任何工具权限。
- **空间与隔离**：整理预览、临时来源与检查点计入独立文字空间，可在笔记内单独清理；笔记删除及账户删除同时清理相应工作。撤销原登录会停止整理请求，迟到结果不能继续写入。

本地识别适用于本次已验证登录后的断网或在线 ASR 不可用场景；网页和 APK 完全断网冷启动仍受页面加载及身份验证限制。浏览器本地模型与后台消息推送不在本版提供。Linux 模型基准不能替代安卓真机麦克风、耗电、发热与后台续录验收。

模型与运行库使用各自上游许可证；权重不应误标为 MIT 或本项目 AGPL。来源、校验值、完整许可和基准见 [本地识别说明](../offline-asr.md)。设备与录音约定见 [安卓客户端](../android-client.md)、[账号切换](../account-switching.md)、[长文整理](../note-organization.md)。

升级包含两个严格追加迁移：新增三个内部表，为原始转录增加七个录音元数据字段与一个索引，不重置用户、项目、笔记或凭据。部署前保留数据库、文件、配置及 service.secret 的完整备份，并验证恢复和迁移幂等。

源码验收已在本机完成：Go 静态检查和账号／听写／整理相关回归、前端完整类型与样式检查、20 个文件共 263 项前端测试，以及桌面与 390px 手机尺寸共 13 项端到端测试通过。Android 编译、10 项 JVM 测试与 lint 通过。中英交替离线样例得到顺序正确的四段转录；这些验证不代替安卓真机的麦克风、温度、耗电与系统后台管理测试。
