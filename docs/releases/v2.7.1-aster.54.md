# v2.7.1-aster.54

本版本完善同实例多账户的助手权限边界，增加独立的只读站点用量页，并让弱网加载提示具体、可测量。

## 账户与阿罗娜

- 阿罗娜内部转发与直接数据库工具均受“本人拥有或明确共享”的业务权限约束；即使账户具有实例管理员身份，也不能借管理权限操作未共享项目。
- 审核等待期间撤销共享后，批准旧计划仍会重新执行权限校验，拒绝无权修改。普通管理入口的许可与行为不变。
- 模型、语音、会话、MCP 和附件继续按账户隔离。不同会话并发及明确共享的协作方式保留。

## 站点用量

- 新增设置中的“站点用量”，支持账户搜索、状态／角色／高数量提示筛选、排序和分页。
- 查看项目归属、近期增长、任务数量、网盘与回收站、星图归属及独立 AI 文件大小。只读统计不解密会话或配置，不返回正文、邮件、文件名、密钥或连接。
- 通过独立的 `ASTERING_USAGE_ADMIN_IDS` 授权活跃真人账户；不继承 SMTP 或实例管理员权限，不提供账户修改或封禁功能。
- 显示快照时间与统计口径；不完整采集按下限标记，网盘复用文件不重复相加，数量提示仅供人工核查。
- 私有结果在身份改变、授权失败或读取失败时隐藏；筛选输入与按钮焦点保持可操作。

## 加载活动

- 泛化的“仍在加载”替换为资源类别、数字标识、等待／重试／接收阶段与已等待时间；可展开逐项查看。
- SDK 文件传输显示实际接收字节及经过采样的近期速度，总大小可信时显示百分比。压缩和未知总量不伪造进度。
- 活动按账户、API 和认证会话隔离，取消、失败及完成及时清理。已有缓存的后台轮询、SSE 与专用上传进度不重复提示。
- 桌面、手机与原生模态框内均可使用；中英文补齐，尊重减少动态效果偏好。

## 星蓝品牌配色

- 保留斜切 A 与小四芒星轮廓，将深色标识的信号黄替换为浅青，配合近白蓝小星；字标与安装图标使用浅蓝底板。
- 同步浏览器、PWA、通知、头像与桌面图标，并更新固定素材缓存标识；不改变账户个人头像或应用主色。

## 本站防护兼容

- 核对本站 1Panel 规则、日志与真实 IP 链路，让 WAF 采用 Nginx 已核验的来源 IP，避免再次信任客户端自报的转发头。
- 保留网站防护、既有兼容规则与限速；不新增整个 API 或上传前缀放行。维护与验证边界记录在[站点防护说明](../1panel-waf.md)。

## 边界与升级

这是共享实例中的多账户协作，不是独立数据库的组织租户。已保存在个人会话中的历史快照不因撤销共享而追溯删除；外部 MCP 的远端资源权限仍由该用户保存的凭据及远端 ACL 决定。加载活动覆盖共享查询冷读取与 SDK Blob 下载，不宣称可测量浏览器每张原生图片或全部流量。

没有数据库迁移，不重置用户、项目、文件或密钥。现有部署只需采用对应产物；如需用量页，由部署者核对真实账户 ID 后显式配置授权。品牌固定素材更新为 `aster54` 缓存标识，既有缓存规则继续使用条件重验证。

源码、Linux amd64 二进制、Docker 镜像包和 Git bundle 均在维护者本机编译／打包，通过 SHA256 校验后手工上传。本仓库不使用 GitHub Actions。详见[账户隔离](../multi-user-isolation.md)与[加载活动](../network-activity.md)。
