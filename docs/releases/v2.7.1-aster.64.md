# Astering v2.7.1-aster.64

录音偏好现在随账户保存，并增加可安装的安卓客户端，让长时间语音记录不再依赖网页持续可见。

- **记住录音选项**：在笔记的「录音选项与连接详情」选择后台延续与屏幕常亮后自动保存，刷新或重新登录同一账户会恢复。保存中、失败及重试均有明确反馈。偏好不自动开启麦克风；开始时固定本次设置，后续账户设置更新不会悄悄改变正在录制的行为。
- **安卓客户端**：提供签名 APK，支持 Android 8.0 及以上，使用本站账户和现有页面。手机后台录音由原生麦克风前台服务运行；需要手动开始并授权，在系统通知中随时停止或返回笔记。关闭后台延续后离开客户端会停止录音；屏幕常亮只在录音页面可见时生效。
- **连续采集与明确异常**：原生识别复用现有实时 ASR 接口，识别连接轮换时持续采集，使用有上限的内存缓冲；网络跟不上时明确暂停，不静默吞音。只保存服务器确认的文字，不在手机或服务器堆积原始录音文件。部分文字只是预览，不能当作已经落库的记录。
- **账户与会话隔离**：原生连接校验固定 HTTPS 站点、账户及当前登录会话，退出或会话变更停止旧录音。后台识别与网页共用受协调的登录续期，不将令牌放进 URL，不向任意网页开放原生麦克风能力。
- **页面更新**：客户端使用网站发布的页面与资源缓存规则；返回前台时同步已保存的转录。原生能力升级需要安装新版 APK，后台不自动打开录音。系统回收、省电限制、麦克风隐私开关及上游故障仍可能中断服务，不能保证所有机型无限常驻。

浏览器继续按浏览器和操作系统能力提供后台选项，保存偏好不会赋予网页锁屏录音权限。安卓录音通知不等于阿罗娜新回复或任务提醒的离线推送，后者沿用站点已有通知能力。

本版本不新增数据库迁移，不改变现有内容及所有权。个人模型密钥、MCP 和笔记继续按账户隔离；APK 不包含预设账号、密码或模型密钥。升级前保留数据库、文件及配置的完整备份。

安装与构建见[安卓客户端](../android-client.md)，录音使用见[实时语音笔记](../voice-notes.md)。检查、签名、编译与 Release 上传均在本机完成，不使用 GitHub Actions。

本机验证已通过 113 项相关前端回归、7 项桌面／手机浏览器端到端测试、TypeScript 类型检查、ESLint，以及 6 项原生 Java 回归、Android Release Lint 和签名构建。实体手机的锁屏、来电、网络切换与厂商省电行为仍需安装后验证；不能把这些自动检查当作各品牌手机均已通过。
