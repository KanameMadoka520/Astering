# Astering v2.7.1-aster.69

本版同时更新网站与 Android 客户端，修复手机子页面留白、网页录音和客户端设置入口。

## 手机页面与录音

- Android 根布局统一避让状态栏、屏幕缺口与键盘，再将已经处理的 Insets 清零交给 WebView，避免网页重复计算安全区；旋转和窗口变化保留原 WebView、页面与草稿。
- 手机全页表单的正文紧接标题，底部按钮保持正常布局；嵌套卡片不再各自撑满一屏。修前浏览器已复现短表单正文上方多出 169px／231px 的空白。
- APK 补齐 Chromium WebView 音频输入所需的普通权限 `MODIFY_AUDIO_SETTINGS`，保留用户明确授予的 `RECORD_AUDIO`。网页麦克风授权绑定原页面、WebView、服务器和账户会话，取消后不接受迟到许可。
- 阿罗娜短语音分别提示权限拒绝、没有麦克风、设备无法启动、格式不支持及录音中断，释放音轨并保留草稿，允许重试。
- 网站同步上线头像菜单里的「客户端设置」。手机阿罗娜页面通过历史抽屉进入站点导航和账户菜单；旧网站或页面不可用时，仍可桌面长按 Astering 图标打开。
- 自动转录写入正文遇到首次读取慢响应时，按服务器确认的文章版本续拉真实正文，避免已保存的最后一句暂时不显示；不覆盖未保存草稿。

## 离线模型安装

安装新版 APK 后，打开「头像菜单 → 客户端设置 → 离线模型管理」，下载完成并通过校验后点击「使用此模型」。也可以在手机桌面长按 Astering 图标进入设置。模型按设备下载一次，支持暂停续传和切换；本版保留 `.68` 的按需下载方案，不把全部权重装进 APK。

APK 仅在 GitHub Release 发布，首次连接地址仍为空，由用户填写。旧版可使用相同包名和签名覆盖升级；升级前保存草稿、结束录音，无需卸载。

## 验证与边界

- 24 项本机浏览器端到端检查通过，覆盖 320px／390px／横屏子页、设置入口、看板任务往返、短表单、语音点按／长按／取消、设备异常和重试。使用隔离账户、合成音频与本地识别回执，不调用付费服务。
- 8 个前端单元测试文件、123 项检查通过；完整 TypeScript、ESLint 和样式检查通过。
- 52 项 Android 单元测试通过；Release lint 无错误，正式签名构建通过；发布时核对版本、原签名、包标识及 16 KiB 对齐。
- 浏览器和声明检查不代替 Android 真机的系统栏、软键盘、麦克风硬件与厂商后台策略验收；本次没有连接 Android 真机。
