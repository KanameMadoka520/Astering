# Astering v2.7.1-aster.61

本次修复最近新增界面中可复现的交互问题，重点覆盖弱网、键盘焦点、会话草稿和手机看板。

- 账户管理：服务器确认操作后即可结束弹窗，列表和用量在后台更新。等待权限复查时保留确认草稿；列表或审计明确拒绝管理权限时清除私有展示。审计分页不再丢失焦点。
- 快速建任务：负责人解析与标签保存期间也保持忙碌，防止连续 Enter 重复创建。任务已保存但部分负责人或标签失败时，准确提示未完成部分，不再误报整个创建失败。
- 批量建任务：部分成功时分别展示已创建、未创建和待补关联的数量，重试沿用已确认的任务 ID，只处理未完成项。同名父子任务按输入位置关联；等待时继续输入的新草稿会保留。
- 项目看板：空白名称提供就地提示；首次加载和每栏分页失败均可原位重试，普通网络错误保留已加载卡片，明确拒绝访问时隐藏旧内容。重新定位正在提交的栏目输入框不再留下已经创建过的名称。
- 阿罗娜：直接打开会话链接和浏览器前进／后退恢复各自草稿；被图片预览等弹窗遮挡的回复保留未读。失败图片增加预览重试，成功下载复用预览数据。
- 新增提示提供中英文；沿用现有账户隔离、图片权限、附件归属和手机布局。

本次为前端修复，无数据库结构或业务数据迁移。检查、浏览器验收和编译均在本机完成，手工发布产物，不启用 GitHub Actions。

验收：396 个单元测试文件全部通过，4352 项通过、1 项沿用既有跳过；强制类型检查、ESLint、Stylelint 通过。浏览器累计验证 97 个不同场景，覆盖 320／390px 手机、1440px 桌面、短视口、暗色主题、请求延迟、部分失败、权限失效和刷新后的实际保存结果。
