# Astering v2.7.1-aster.74

修复阿罗娜「场景与偏好」中编辑模型、权限或预算后，个人模板从下拉框里消失的问题。编辑时保留模板名称和更新目标，点击「更新此模板」后可在其他会话中复用。点击「用于接下来的对话」则应用到下一条消息。

- 服务器确认保存后立即更新模板列表；网络慢时，可以继续使用新设置，无需等待后台刷新。
- 保存期间切换场景或继续编辑，较早的响应不会替换新选择。遇到版本冲突，重试先读取账户的新版本，保留正在编辑的内容。
- 用真实浏览器和隔离测试库验证选择、更新、应用和刷新后的结果，并覆盖桌面与手机宽度下的模板操作。

此版只发布服务端与网页修复。Android 客户端可继续使用 [2.7.1-aster.73](https://github.com/KanameMadoka520/Astering/releases/tag/v2.7.1-aster.73)，连接已升级的服务端即可使用修复后的界面。
