# Astering v2.7.1-aster.63

阿罗娜现在可以按用户选择读取和整理个人笔记。笔记是一项独立的工具能力，默认关闭，单纯整理用户带入聊天的文字不需要打开它。

- **可选的笔记权限**：打开聊天的「对话配置 → 工具」，将个人笔记设置为关闭、只读或读写，也可以保存为个人场景模板。已有会话和旧模板不会自动获得笔记权限。执行与等待审核期间沿用本轮配置，停止后再变更下一轮范围。
- **按需使用六项工具**：搜索笔记、分段读取正文、分页读取原始转录，以及创建、修改和删除笔记。工具定义按需发现，列表只返回摘要，正文和转录分别分页，避免长篇内容无条件进入每轮上下文。
- **写入前审核**：笔记创建、修改和删除均需逐次审核；删除另需开启本轮删除许可。更新保留未提供字段，按读取的版本保存；删除还在事务锁内检查审核后的正文和转录变化，避免覆盖新稿或误删新录入的文字。
- **保持个人边界**：只能访问当前真人账户自己的笔记；实例管理员、团队、项目共享和外部 MCP 不授予其他人的笔记权限。笔记工具不会开启麦克风、启动识别或改写原始转录。
- **局部同步与草稿保护**：执行成功后刷新相关笔记，标记个人空间统计需要更新，不重载整个页面。修改不覆盖当前未保存正文；版本冲突继续由编辑器提示处理。阿罗娜删除笔记时，当前页面的未保存草稿暂留为只读内容，可复制或导出，不会重新保存成已删除的笔记；离开后不持久保留。
- **明确来源与授权**：从原始转录带入聊天的草稿附带源笔记标识，便于准确定位，但不自动发送、不打开笔记权限，也不替换已有聊天草稿。中文、英文和手机工具入口保持一致。

本版本不新增数据库迁移，不改变现有笔记、转录、项目、任务和附件的归属及保存格式。长听写继续只保存识别文字，原始音频不落盘。升级前保留数据库、用户文件和配置的完整备份。

使用说明见[个人笔记工具](../agent-tool-modules.md#个人笔记工具)与[实时语音笔记](../voice-notes.md)。本版本在本机检查、构建并手动发布，不使用 GitHub Actions。
