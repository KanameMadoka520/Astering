# v2.7.1-aster.57

本版本重新整理阿罗娜的手机对话页面，让正文、输入和正在执行的步骤更清楚，并补全从对话图片到任务描述的附件查找链路。

- 手机对话只保留一行会话顶栏。全站导航、搜索、通知、账户和计时入口移入可打开的站点抽屉，继续复用现有组件与状态。
- 输入栏保留文字、附件、语音、当前模型与工作方式摘要、发送／停止／插话；完整模型、场景、联网、工具模块、MCP、权限和运行设置按需展开，执行中的权限范围保持锁定。
- 会话存储占用、附件数及压缩记录移到会话详情；回复默认保留模型、GMT+8 时间、真实耗时与已报告的输出速度。Token、缓存、轮数和调试详情可展开查看，错误、审核、重试和执行阶段仍直接可见，中间工具记录沿用原显示偏好。
- 布局跟随实际可见视口，处理键盘只缩小 visualViewport 的情况、横屏、安全区与手机浮窗；不重新挂载聊天或丢失草稿。配置、详情和覆盖式抽屉遮住正文时不提前清除未读。
- 新增按需发现的只读 `list_chat_attachments`：分页提供本轮可见且已发送到当前会话的附件 ID、文件名、类型、大小与缺失状态。不会发送图片字节、下载密钥或内部存储信息，未发送草稿与其他会话／账户附件不会进入清单。
- 当前附图在模型请求中带上与像素对应的真实附件 ID；缺少 ID 或上下文压缩后可通过清单找回，再复用现有任务描述布局、插入、移动、替换和移除图片工具。任务权限、描述版本、文件引用与写入审核继续由服务端校验。

本次不改变数据库结构、注册设置或品牌固定资源；沿用原有数据及密钥，品牌资源缓存令牌仍为 `aster54`。源码、检查、编译与发布均在本机完成，GitHub Actions 保持关闭。

设计及维护边界见[手机对话布局](../arona-mobile-chat.md)、[浮窗布局](../floating-arona-layout.md)和[外部 MCP 与聊天插图](../external-mcp-and-chat-images.md)。

本机验收：完整强制 TypeScript 检查通过，前端及样式 lint 无错误；相关前端单元测试 83 项通过。真实 Chromium 的 33 项回归覆盖 320／390／430px、768px 横屏、1440px 桌面、中英文、深色空会话、长草稿、实际发送与追加／停止、语音、外链、历史步骤、遮挡期间未读、浮窗及键盘只改变 visualViewport 的布局；另检查中文面板稳定状态截图，并通过 390／1440px 两项嵌套配置交互：实际切换模型、工具模块、MCP 与权限，校验发送参数、返回焦点、草稿节点及运行中锁定。未使用实体手机，键盘场景是独立的浏览器视口事件模拟。
