# Astering v2.7.1-aster.60

本次完善同一实例内的账户管理与隔离，并改进手机看板的阅读和操作。

## 账户管理

- 新增「设置 → 站点 → 账户管理」，由部署者通过 `ASTERING_SUPERADMIN_IDS` 显式指定超级管理员。
- 按账户查看状态、项目／任务数量、归属存储、登录设备和 API 令牌数量；支持搜索、筛选、分页和数量提示。
- 停用／恢复普通账户，以及撤销其登录凭据。操作前确认目标账户和影响，操作审计持久保存。
- 停用保留业务数据，撤销现有登录与名下机器人凭据并停止助手后台执行；恢复时同样清理残留旧凭据，兼容此前由 CLI 或旧入口停用的账户，要求重新登录。
- 保护当前操作者和全部配置超级管理员；普通账户、机器人、API Token、分享和资源受限的助手执行身份不能使用管理接口。
- 超级管理员身份不扩大阿罗娜的项目、星图、网盘、模型配置或 MCP 权限。只读用量、SMTP 与上游许可管理维持各自独立授权。
- 修复离线排队修改在切换账户后恢复时重新捕获身份的问题，保持每次执行原有的账户、认证会话与 API 边界。
- 兼容待验证用户的默认项目初始化与已停用账户清理；保留未验证账户刷新登录时的失效会话清除，以及管理员分享链接的根项目级联删除语义。
- SQLite 临时账户读锁使用有上限的只读重试，避免阿罗娜因短暂锁冲突中断；仍逐次核对当前账户状态，不放宽权限或重放写入。

## 手机看板

- 增加栏目跳转与上一栏／下一栏入口，跳转只滚动看板。
- 普通卡片提供「移动到栏目」操作，不必长按拖过多个屏幕。
- 将拖动入口收敛到明确把手，保留卡片点击打开详情的触控区域。
- 改进长标题、栏目名称和新增任务／栏目的操作，保留完整内容与未提交草稿。
- 移动任务后展开并定位实际目标栏目，保持栏目选择器、可见卡片和保存结果一致。
- 删除任务后替换当前历史地址，保留原页面查询与锚点，避免浏览器返回时重开已删除任务。
- 继续使用共享查询层局部同步，保留分页、滚动和任务关系显示偏好。

## 本机验证

- 前端完整单元测试：395 个文件、4,285 项通过，1 项既有跳过；完整类型检查、代码与样式检查通过。
- 完整后端 feature 测试及静态检查通过；SQLite WAL 完整 Web 测试 362 个顶层用例通过，4 个条件跳过（两个未配置的 LDAP 用例、两个仅适用 PostgreSQL 的并发用例）。
- 隔离 PostgreSQL 18.6 验证 51 个顶层用例通过，无失败或跳过；15 项必选安全回归均实际执行，包括凭据撤销竞态、旧账户恢复、事务回滚和项目历史权限复查。
- 真实 Chromium 浏览器回归 41 项全部通过，覆盖 320px／390px 手机看板、1440px／390px 账户管理、只读权限、长标题、远距离移栏、分页和删除后返回。

验证使用隔离测试数据。上述两个 PostgreSQL 专用并发用例不在本次账户专项 PostgreSQL 筛选范围内，未将它们记为本次已执行。

部署前使用实际运行版本的完整备份进行隔离恢复和升级验证；新增审计表，不重写既有账户与业务记录。源码、测试、编译与发布产物均在本机完成，不启用 GitHub Actions。

当前账户停用与后台任务取消按单个应用进程协调。公开分享链接是独立授权对象，停用账户不自动撤销既有公开链接；如需停止公开访问，应单独撤销分享。

权限与使用边界见[多账户说明](https://github.com/KanameMadoka520/Astering/blob/v2.7.1-aster.60/docs/multi-user-isolation.md)，看板显示规则见[看板说明](https://github.com/KanameMadoka520/Astering/blob/v2.7.1-aster.60/docs/kanban-display.md)。
