# Astering v2.7.1-aster.73

新增服务器端自动化与显式无人值守审核策略。浏览器关闭后仍能按计划运行阿罗娜或发简单提醒，普通会话也可以在本人授权范围内直接执行操作。Android 客户端同步更新到 `.73`，增加独立的后台通知与任务提醒。

## 自动化

- 侧栏独立入口，支持空白计划和早间概览、每周回顾、简单提醒模板。时区、下次执行、模型、工具模块、项目写入范围、MCP 选择与通知设置集中在单个草稿中。
- 支持一次性、每天、工作日、每周多天、每月、每年、固定间隔；提供暂停／恢复、立即运行、编辑、删除和执行历史。暂停未来计划与停止当前会话保持不同含义。
- 每次模型执行生成独立会话，保留真实工具回执、用量和错误；纯提醒不请求模型。后台参数使用准入时快照，编辑计划不改变已开始的工作。
- 持久化防重收据后才开始执行，同一计划不重叠。断网重试复用请求编号，重启未知结果明确标为中断，不重放已经可能执行的操作；停机错过的重复时间合并，避免恢复后积压补跑。
- 计划及近期执行摘要按账户加密；设置的空间页和管理员用量准确计量，配置不进入批量垃圾清理。结果会话另行保留，删除计划不删除业务成果。

## 无人值守与隔离

- 普通会话、偏好模板和自动化增加「无人值守」策略，在已授权范围内跳过人工点击。智能、逐项和原自动处理策略保持各自语义。
- 精确操作仍先准备提案并检查当前版本；项目、模块、任务／笔记删除、MCP 选中连接、资源角色及账户权限继续生效。没有把系统管理员身份或历史配置当作业务授权，也不伪造人工审核字段。
- 后台执行使用与原真人账户绑定的有界服务会话，仅内存持有凭据；完成、失败或停止后撤销，账号停用与登录凭据撤销继续有效。机器人、API Token、分享及模型内部身份不能创建新的持续执行授权。
- 提醒沿用站内通知和本人 Bark 设置，清楚区分站内保存与实际设备送达；错误与完整模型内容保留在私人会话。后台规则不会因传输失败自动重新执行业务操作。

## 安卓通知与任务提醒

- 客户端设置新增「通知与提醒」，用户主动开启并授予系统权限；支持后台摘要同步、已同步时间的本地提醒、未读摘要和启动器支持的桌面角标。
- 个人事项包含分配给我、我创建或有效关注的任务，保持当前项目 ACL、完成／归档及订阅静音语义。已有明确提醒优先，默认日期提醒可单独控制；近期截止、近期安排、逾期和未读分别计量。
- 使用系统 WorkManager 与 AlarmManager，不借录音服务保活，不后台开麦；普通闹铃与可选精确授权如实说明，未接入 FCM，不宣称实时推送或绕过系统省电限制。
- 独立 30 天只读设备令牌只能获取最小提醒摘要，按安装 UUID 轮换；不会把完整登录 JWT 为通知保存到磁盘。设备密文、通知点击和异步请求保持来源、账户与本机代次隔离。
- 通知点击采用固定资源类型的站内导航，保留草稿保护；任务变化及通知已读会合并请求重新同步。默认隐藏私人预览，原生录音通知不影响消息角标。
- APK 仅上传本仓库 Release，连接地址默认空白，继续使用原签名并递增版本。Android 原生构建、单元测试和 lint 在本机完成；本机没有安卓实机或模拟器连接，设备省电、许可和具体角标仍需手机验收。详见[安卓通知](../android-notifications.md)。

## 交互与维护

- 覆盖桌面、窄屏、中英文、夏令时重复小时、弱网重试、编辑期间后台更新，以及账号／服务器切换。草稿不会被轮询结果覆盖，同身份 JWT 续期不关闭编辑器。
- 复用现有会话运行器、工具协议、生成 SDK、查询上下文与存储保护；不引入另一套模型循环或前端业务数据持久缓存。
- 将自动化的权限、幂等、备份和发布维护要求加入后续 agent 必读文档，详见[自动化说明](../automations.md)。
