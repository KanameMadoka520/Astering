# Astering v2.7.1-aster.70

阿罗娜短语音改为真正的实时识别，转录原文先可用，文字整理不再阻塞输入。本版更新网站与服务端，Android 原生客户端继续使用已发布的 `.69`；页面功能随所连接站点更新，无须为本次网页升级重新安装 APK。

## 语音输入

- DashScope／Qwen 实时协议复用 AudioWorklet 和纯识别适配器，边录边发送 16 kHz PCM，显示实时字幕。其他协议与上传音频保持文件方式。
- 转录原文一到即可编辑或发送；自动整理使用独立请求。用户修改过草稿时，整理稿单独展示供复制，不覆盖修改；发送后不会被迟到结果重新填入。
- 停止时先收齐尾帧、排空音频队列，再等待服务商最终完成确认；取消、切换账户或隐藏窗口会关闭本次识别。中断的实时预览可手动复制，不把临时字幕当成成功，也不自动重传付费请求。
- 默认收起的识别详情显示模型、实际端点、追踪编号及停止到文字可用、首字、收尾、整理耗时，不编造未知网络比例。
- 修复长按录音达到时长上限后，松手误取消正在收尾的识别；音频上下文启动失败会及时提示并释放麦克风。

短语音不创建笔记、网盘文件或会话附件，不保存录音；独立校验当前人类登录会话、账户状态及连接归属。容器收到 SIGTERM 时会进入现有的优雅关机流程。

## 实测与验证边界

2026-11-11 使用公开 5.592 秒中文样例、同一 Qwen 3.1 Streaming 连接：文件识别耗时 2.407 秒，后续 GPT-6-luna 整理 3.732 秒；实时送音频停止后 0.378 秒获得最终结果，录音期间收到 6 次中间结果。此为单次服务端至服务商测试，未计手机上行与浏览器调度，不能视为端到端延迟保证。

本机后端回归和 lint 通过，6 个前端单元测试文件共 158 项通过，浏览器 36 项通过。覆盖真实双 WebSocket 上游、最终结果与容量边界、会话撤销和身份拒绝；浏览器用合成音轨检查实际 AudioWorklet、桌面及 320／390px 手机操作、停止与取消、整理挂起和草稿竞态。慢网用例约束页面 HTTP 加载，识别通道使用可控延迟回执，不把模拟 WebSocket 宣称为真实公网测速。测试使用隔离数据和本地识别回执，不调用付费接口。没有连接 Android 真机，系统麦克风硬件与厂商省电策略仍需真机验证。
