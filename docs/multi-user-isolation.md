# 账户隔离与站点用量

Astering 支持同一实例中的多个账户，通过项目用户／团队共享进行协作。它不是为每个组织分配独立数据库、独立加密主密钥和独立运维管理员的 SaaS 租户系统；操作系统与部署管理员仍属于受信任边界。

## 阿罗娜的权限

| 内容 | 使用范围 |
|---|---|
| 模型与语音设置、密钥 | 当前账户独立加密保存；读取接口不返回密钥。 |
| 会话、运行、审核与附件 | 绑定账户和会话；不能通过别人的 ID 获得访问权。 |
| 外部 MCP | 只使用当前账户保存且本轮选中的连接；连接开关、修订、凭据目的地与审核持续校验。 |
| 项目与任务 | 本人拥有，或明确共享给本人／所属团队；只读共享不能写入。 |
| 星图 | 保留空间权限和独立工具模块开关；不会因模型猜到 ID 而授权。 |
| 网盘 | 个人原件按所有者隔离；共享任务附件遵循任务权限，不转移个人网盘所有权。 |

模型不是授权主体。执行层同时约束工具模块、读写模式、项目范围、账户业务权限和操作审核。阿罗娜内部 HTTP 转发与直接数据库工具均携带可信的“仅资源权限”范围：即使用户在已启用的实例管理功能中拥有额外权限，助手也不能借此绕过未共享项目的 ACL。原账户的普通管理界面行为不变；该标记不进入数据库、JSON 或 JWT，也没有可由外部设置的请求头。

审核期间撤销共享后，批准旧计划也不能执行新的无权修改。不同账户的配置、会话和 MCP 凭据不自动共享。外部 MCP 服务究竟允许访问哪些远端数据，仍取决于当前用户给该服务配置的凭据和远端 ACL，不能由 Astering 代替远端授权。

撤销项目共享会阻止新的源资源访问；不会追溯擦除用户此前已经获得并保存的个人对话快照。需要追溯删除时，应另行制定数据保留规则，不能静默清除历史。

权限设计遵循服务端逐次授权与默认拒绝原则，参考 [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) 与 [Multi-Tenant Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Multi_Tenant_Security_Cheat_Sheet.html)。这些参考不等于独立安全认证。

## 独立、只读的站点用量

部署者通过 `ASTERING_USAGE_ADMIN_IDS` 配置允许查看用量的账户 ID，以逗号分隔。例如 `2,5`。未设置、空值或移除 ID 均不授予权限；不会继承 SMTP 配置管理或实例管理员角色。实际部署应核对账户 ID，不能照抄示例给未知账户授权。

仅已认证、状态正常的真人会话可以使用；API Token、机器人、待验证、禁用、锁定和已删除账户被拒绝。服务端每次请求重新核对身份与授权，前端入口隐藏不是安全边界。接口为：

- `GET /api/v2/system/usage/access`：当前账户是否能查看。
- `GET /api/v2/system/usage/users`：分页、搜索、状态／角色／数量提示筛选及排序的统计快照。
- 页面：`/user/settings/usage`，位于设置的站点分组。

这项 Astering 原创运行观察能力不改变上游许可开关，不提供账户创建、改密码、提升权限、封禁、删除、原文或凭据访问，也不进入阿罗娜工具目录。

## 统计口径

项目按**当前所有者**归属，包含归档；近期 24 小时／7 天数量按创建时间及当前所有者计算，不能解释为最初创建者。任务分别统计“拥有项目中的非软删任务”与“由此账户创建的非软删任务”，两者不相加。

文件按原件 ID 去重，使用数据库记录的逻辑原件长度，包含尚保留的回收站文件。网盘及回收站是子集，不再次相加；同原件多次引用只计一份。AI 会话、旧独立附件、模型与 MCP 配置只读取规范加密文件的元数据，不解密。新网盘附件已在原件中统计，不重复加入 AI 附件。

“归属存储”＝上传原件逻辑大小＋独立 AI 密文文件长度。它不等于服务器磁盘实际分配，不含预览、数据库／索引／WAL、备份、临时与孤立文件。概览仅覆盖已持久化账户的归属，匿名／分享链接上传不强行归给某个用户。星图按空间所有者归属，含团队空间、归档与回收站条目，不授予正文访问权。

快照最多缓存 30 秒，从采集开始计时；SQL 分组采集避免每个账户单独查询。文件系统扫描有总预算与取消检查，不递归读取业务内容；不完整值显示为已知下限，不能当作确定零。刷新失败或权限被拒绝时隐藏旧私有快照。采集可能与写入同时发生，不能作为停写一致性备份。

提示阈值为拥有至少 1,000 个项目，或近期 24 小时创建且仍拥有至少 100 个项目，或 7 天至少 500 个项目。只提示人工核查，不证明滥用，不自动限制或修改用户。
