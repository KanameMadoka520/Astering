# 星辰主题

从 `v2.7.1-aster.53` 起，Astering 提供独立的 **星辰（Starlight）** 深色主题。它在近黑色背景上放置稀疏星点与淡星座线，保留正文、任务卡片、表单及弹窗的实色表面。星空属于背景，不能妨碍阅读、点击或任务状态的辨认。

## 开启与保存

打开 **设置 → 通用设置 → 外观与行为 → 配色方案**，选择 **星辰**，然后保存设置。选择保存在当前账户的 `frontend_settings.color_schema` 中，重新登录和其他设备读取账户设置后继续使用。原来的跟随系统、浅色和深色选项保留；升级不会替任何账户强制改为星辰。

外观设置中的小预览用于辨认效果，正式全站配色在成功保存后应用。切回原配色并保存即可恢复；星辰是固定深色，不随系统浅深色切换。只有“跟随系统”追随浏览器的系统偏好。

浏览器沿用现有 `vikunja-color-scheme` 本地键，仅保存已应用的浅色、深色或星辰外观提示，帮助下一次启动尽早显示相同底色。此键是兼容标识，不必随品牌改名。账户资料才是偏好的最终来源；该提示不包含任务、会话、文件或密钥，也不是业务离线缓存。应用等待首次路由认证完成后统一接管主题类，避免加载账户之前用默认值覆盖启动提示；外观提示读写失败不会阻断主题应用；这不代表其他依赖本地存储的登录功能也能在全局禁用存储后运行。

## 视觉与已有页面

- **底色与文字**：近黑夜色、蓝灰表面与浅灰文字。边框、次要说明和控件沿用共享 token，避免每个页面另造一套主题。
- **背景**：本地原创 SVG 中的静态星点、淡星座线及少量暖黄／浅青光点，叠加两层很淡的径向光晕。手机使用更疏的图案比例；背景没有鼠标跟踪、闪烁或持续动画。
- **任务与记录**：既有项目背景、星图空间图片仍在自己的层级显示，不被全站星空覆盖。图片上原有的遮罩和内容表面继续决定可读性。
- **阿罗娜**：完整对话页仅在阅读区外侧留出星空，正文、输入区和悬浮窗口保持实色，不让图案穿过长篇内容。
- **打印与快速添加**：全站星辰 token 和背景仅用于屏幕；打印沿用现有打印配色。桌面快速添加窗口保留透明背景，不被全局星空填满。
- **强制颜色**：系统强制颜色模式下去掉全局和对话页的装饰背景，由系统的高对比显示规则处理内容。

星辰主题不改变用户的品牌头像、阿罗娜角色图或个人账户头像。小星版品牌的设计、深浅色和平台图标规则见[品牌素材](brand-identity.md)。

## 实现与性能边界

入口在 [GeneralSettingsForm.vue](../frontend/src/views/user/settings/GeneralSettingsForm.vue)，账户设置类型在 [userSettings.ts](../frontend/src/helpers/userSettings.ts)。[useColorScheme.ts](../frontend/src/composables/useColorScheme.ts) 只计算共享状态，[App.vue](../frontend/src/App.vue) 负责统一应用主题和更新外观提示；[index.html](../frontend/index.html) 的启动脚本只负责尽早恢复提示，不产生第二套持续主题状态。

样式位于 [starlight.scss](../frontend/src/styles/theme/starlight.scss)，星点为 [starlight-stars.svg](../frontend/src/assets/starlight-stars.svg)。素材随构建产生内容哈希资源，使用现有[静态缓存策略](browser-cache.md)，不从外站获取背景、不增加新的运行服务或依赖。

静态 SVG 与渐变仍需浏览器绘制，不应声称“零成本”或保证所有设备的帧率。这里避免的是常驻 Canvas、逐帧遍历星点、动画循环和重复请求；验收应查看实际构建体积、桌面与小屏渲染、滚动及交互，而非只确认 CSS 类存在。

## 设计参考与维护

背景层次参考了 [docs.bulai.app](https://docs.bulai.app/) 的实际暗色页面：近黑底、稀疏光点、细淡连线与克制光晕。Astering 的 SVG 图案与主题实现为本项目重新制作，没有复制该站素材、脚本或品牌。参考站的动态效果没有作为本站运行时依赖。

维护主题时验证保存与重新加载、原有浅色／深色／跟随系统的恢复、首次路由加载竞态、中英文和手机布局，以及项目／星图自定义背景、打印和快速添加窗口。涉及共享控件说明时同时检查 `aria-describedby` 能关联帮助与错误信息。真实测试结果按发布记录保存，本文不代表未来改动已经通过验收。
