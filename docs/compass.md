# 星图 / Compass

星图是 vikunja-x 里一间私人的阅览室：用来写下原则、理想、行动纲领和长期记忆，并在迷失方向时回来重读。它不是任务列表，也不是效率仪表盘——没有完成率、没有统计卡片、没有任何替你写好的“人生信条”。界面里的天色与星盘只是装饰，不代表任何数据。

侧栏「记录与回顾」第一项进入（`/compass`）。界面名“星图 / Compass”是功能名；每个空间的标题可以随时改。

## 概念

| 概念 | 说明 |
| --- | --- |
| 空间 | 一本书。有标题、座右铭（纯文本）、序言（富文本）和主题（极光 / 日冕 / 星云 / 墨）。 |
| 条目 | 书里的一篇。五种类型：原则、理想、行动纲领、记忆、札记。可以有副标题、题记（一句引语）、分类（自由文本）和最多 24 个标签。 |
| 指引 | 置顶的条目，显示在空间首页最上方，用题记或副标题作为大字。 |
| 书库 / 归档 / 回收站 | 条目的三个状态。归档仍可阅读，不在书库默认列表里；回收站中只读，可恢复，管理员可永久删除。 |
| 版本 | 每次内容确有变化的保存都会留下一个完整版本，可浏览、可恢复（恢复会生成新版本，不覆盖历史）。 |

## 隐私与共享

- 新空间默认**私人**：只有自己能看到，实例管理员也无法浏览。
- 也可以在创建时选择**与团队共享**：只能选择你担任管理员的团队。该团队的当前成员可以阅读和写条目，团队管理员管理空间设置和永久删除。共享方式创建后不能更改。
- 不支持链接分享，也不会自动公开；链接分享会话访问星图路由一律 404。
- 阿罗娜不读取、不改写星图内容；星图内容不会进入 AI 上下文。

## 页面

| 路由 | 页面 |
| --- | --- |
| `/compass` | 读取空间：没有空间时显示欢迎页（一键创建私人星图，或自定义 / 团队共享）；有空间时打开上次打开的空间（本机按账户与服务器记忆），否则第一个私人空间。 |
| `/compass/new` | 新建空间，带实时天色预览。 |
| `/compass/spaces/:id` | 空间首页：天色带（标题、座右铭、可见范围）、指引、序言、书库（搜索、类型、状态、排序、分类与标签、分页）。筛选全部写在地址栏，后退可还原。 |
| `/compass/spaces/:id/settings` | 空间设置（仅空间管理权限可改）。 |
| `/compass/spaces/:id/write` | 写新条目（`?kind=` 预选类型）。 |
| `/compass/entries/:id` | 阅读：题记、正文、目录、阅读进度、阅读设置（衬线/无衬线、字号）、导出 Markdown、打印。 |
| `/compass/entries/:id/edit` | 编辑。 |
| `/compass/entries/:id/history` | 版本历史与恢复（`?revision=`）。 |

空间没有任何条目时，书库给出五个“提问式邀请”，每个类型一个问题，点开是空白的编辑器——问题只是引子，不会写进内容。

## 写作与保存

- 显式保存：保存按钮或 Ctrl/⌘+S（正文编辑器里 Ctrl/⌘+Enter 同样保存）。状态栏始终说明“已保存 / 有未保存的更改 / 草稿已存于本机 / 保存中 / 保存失败”。
- 本机草稿：有改动 0.8 秒后写入浏览器本地存储，键为 `tcymc-compass-draft:v1:{API}:{用户}:{空间}:{条目或 new}`，不同账户、服务器、空间、条目互不混用。保存成功或明确放弃才删除。浏览器拒绝存储时（隐私模式、配额满）只保留在当前页面并提示尽快保存。
- 断网时，已经打开的星图页面保留在屏幕上，仍可编辑并保留本机草稿；点击保存会立即提示失败，不会静默排队等联网后擅自提交。恢复网络后可手动保存。
- 离线时点保存会立即失败并说明原因，文字留在编辑器和本机草稿里；不会排队在之后（或换了账户后）自动发送。星图页面在断网时不会被全站“离线”页替换。
- 离开未保存的编辑页会询问：继续编辑 / 保留草稿离开 / 放弃更改离开；关闭标签页由浏览器提示。
- 重新打开时：草稿基于当前版本会直接恢复并提示；基于旧版本则列出不同的字段，在你选择“继续编辑草稿（保存时覆盖最新版）”或“放弃草稿”之前，写作台暂不可编辑。
- 版本冲突（别人或另一个标签页先保存了）：保留你的文字，展示最新版本的作者、时间、差异字段和内容预览，可选择“保留我的版本”（再次保存即有意覆盖）或“使用最新版本”。
- 置顶、归档、回收站不属于编辑草稿；在阅读页改这些不会抹掉草稿，只会让草稿的基准变旧，下次保存走冲突流程。
- 条目被永久删除后仍可把编辑器里的文字“另存为新条目”；进入回收站的条目需先恢复再编辑。
- 编辑器支持标题、列表、引用、代码、表格、链接等文字格式；不支持图片和任务清单。所有正文按严格白名单渲染（无图片、无脚本、无样式），链接在新窗口打开并带 `noopener noreferrer`。

## 导出与打印

- 单篇：阅读页「导出 → 下载 Markdown」。文件带 YAML front matter（title、kind、category、tags、pinned、state、created、updated、revision），随后是标题、副标题、题记（引用块）和正文。下划线、高亮、上下标以内联 HTML 保留。
- 整个空间：空间首页「导出」，逐篇读取书库与归档（不含回收站），生成一个带目录的 Markdown 文件；可取消。
- 打印：阅读页「打印」只打印文章本身：白底黑字衬线、保留题记、链接后附网址、标题不与下一段分页，使用完整日期，长代码自动换行。

## 设计语言（维护时请保持）

- 文字为主：标题、题记、正文使用系统衬线字体栈（不下载字体）；正文行宽约 38em，行高 1.85。
- 只有空间首页顶部有天色带：主题渐变 + 静态星盘细线（`CompassSky`，固定种子、`aria-hidden`、打印隐藏）。这是对全站“无大渐变”规则的有意、唯一的例外；阅读、编辑、历史页保持纸面+细线。
- 主题变量都在 `CompassThemeScope`：`--compass-sky-*`、`--compass-glow-*`、`--compass-star`、`--compass-accent(-tint)`、`--compass-kind-*` 等，暗色覆盖放在 `:root.dark … @media screen`，打印恒为浅色。强调色只用于小面积，并保证正文级对比度。
- 五种类型各有细线符号（`CompassGlyph`）：原则=北极星，理想=地平线上的星，行动纲领=罗盘指针，记忆=带尾迹的星光，札记=小星与边注。符号总伴随文字。
- 无持续动画；只有不超过 220ms 的透明度/位移过渡，`prefers-reduced-motion` 下全部关闭。
- 320px 不出现页面横向滚动；宽表格在自身容器内滚动；触屏目标 ≥ 44px；焦点可见。

## 前端结构

| 位置 | 内容 |
| --- | --- |
| `client/queries/compass.ts` | 键、normalize、查询与全部写入（`contextMutationOptions`）。置顶/归档/回收站/恢复先读取最新详情，再以完整字段 PUT，只改元数据。 |
| `composables/useCompass.ts` | 只读查询封装、账户命名空间、成员显示名。 |
| `composables/useCompassReadingPrefs.ts`、`useCompassEntryDraft.ts` | 阅读偏好、草稿生命周期。 |
| `helpers/compass/` | 常量与限制、草稿与本地存储、书库地址栏状态、错误分类、正文准备（清洗 + 目录锚点 + 阅读时长）、HTML→Markdown、导出。 |
| `components/compass/base/` | 主题作用域、符号、星盘、正文排版、类型/状态徽章、主题选择、永久删除确认。 |
| `components/compass/{space,library,reader,history,editor,settings}/`、`views/compass/` | 各页面。 |

缓存：列表按空间与筛选分页缓存，同一空间内翻页保留旧数据；写入后精确修补详情与列表行，再失效该空间的列表、话题、空间计数和历史。正文只在打开条目时读取，列表不含正文。

## API

全部在 `/api/v2`，操作 ID 与生成 SDK 函数一一对应：

| 接口 | 用途 |
| --- | --- |
| `GET/POST /compass/spaces` | `compass-spaces-list` / `compass-spaces-create`（不会自动创建空间） |
| `GET/PUT/PATCH /compass/spaces/{space}` | 读取 / 带 `revision` 保存 |
| `GET/POST /compass/spaces/{space}/entries` | 分页列表（`q`、`kind`、`category`、`tag`、`state`=active/archived/all/trashed、`pinned`、`sort`）/ 创建 |
| `GET/PUT/PATCH /compass/entries/{entry}` | 读取 / 带 `revision` 保存 |
| `DELETE /compass/entries/{entry}?revision=N` | 仅回收站中的条目、管理权限，连同全部版本永久删除 |
| `GET /compass/entries/{entry}/revisions[/{revision}]` | 版本列表（无正文）/ 某版完整快照 |
| `POST /compass/entries/{entry}/revisions/{revision}/restore` | `{expected_revision}`，以该版内容创建新版本，保留置顶与状态 |
| `GET /compass/spaces/{space}/topics` | 分类与标签计数（不含回收站） |

错误码：409 / 20101 版本冲突，404 / 20102 不存在或不可见，400 / 20103 状态不允许该操作。
