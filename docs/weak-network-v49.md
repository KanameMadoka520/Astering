# 弱网体验设计与验证

本次针对共享加载路径，以及星图分类、日历、网盘、项目时间线和阿罗娜之间的实际切换进行优化。网络限制会影响首次访问及必须重新鉴权的请求；优化不承诺离线编辑或跳过权限检查。

## 共享加载路径

- Service Worker 安装和更新不再预取全部页面资源。构建清单只作有限、精确的公开哈希资源白名单；实际请求并收到正确类型、公开且可长期缓存的响应后才写入当前版本缓存。HTML、API、私人文件及外站请求不进入这条缓存路径。清理仅针对本应用同作用域拥有的旧缓存，更新仍由用户确认。
- 同一账户、API 地址、认证会话和有效 JWT 已经验证后，周期账户资料更新在后台执行；并发请求复用，临时失败按 60–600 秒退避。首次认证、令牌过期、身份变化及管理员页面仍等待验证。401/403 先撤掉本地身份与私人查询缓存，再处理服务端退出。
- 普通读取仅对连接失败、408 和服务器临时故障重试一次，不重复请求 4xx、取消或已终止操作。日历多页读取在失败页重试，不重拉已经成功的前缀；失败仍不返回不完整的日历数据。
- 冷数据读取持续超过 1.2 秒时给出一个可以关闭的加载提示；已有数据的例行后台刷新不反复打扰。提示不伪造百分比或预计剩余时间。
- 页面分块下载失败保留当前页面与输入。恢复通过正常路由重新尝试，继续执行原路由权限检查。部分浏览器会在当前文档记住失败的模块，即使网络恢复，重复导入仍失败；此时明确提示先保存编辑，再由用户选择刷新。禁止自动整页刷新。

移除正式构建中只为开发使用的 Vue DevTools Vite 插件；其他依赖中名称含 `devtools` 的库文件仍可能存在，不能据文件名宣称所有相关代码都已消失。

## 列表与编辑状态

星图保留同一空间已经显示的列表，并标注正在切换、后台刷新或等待联网。初始错误提供重试，后台错误保留旧结果并明确说明；403/404 不继续展示旧列表。已访问分类复用当前账户的查询缓存，不把私人记录持久写入浏览器离线存储。

日历和项目历史在等待新日期范围、年份或筛选时保留旧内容，显示其仍属于上次范围，不能把旧内容标为新范围的结果，也不能把离线等待显示成零条。身份、API 或认证会话变化时舍弃旧快照。新数据与阿罗娜成功操作通过共享查询层定向同步，不刷新整个文档，不清空未保存草稿。

具体 HTTP 缓存和私人图片规则继续遵循[浏览器缓存与私人图片](browser-cache.md)。业务数据的短期内存复用与浏览器公开静态资源缓存是两套边界，不能混为一谈。

## 可重复的本机验收

前端单元回归覆盖账户刷新竞态与撤权、模块恢复失败、静态资源白名单、不可缓存响应、查询重试和分页、工具权限选择及定向回执更新。后端通过 Mage 执行 `TestTCYAI`，覆盖发现、直接调用、审核、历史引用、恢复重试、子代理与星图真实 HTTP 权限和版本冲突；不向真实模型服务发送验收请求。

浏览器验收统一使用 `mage test:e2e`、隔离数据库和 Chromium。相关用例：

| 场景 | 测量或断言 |
| --- | --- |
| 星图分类切换 | 1500 ms 延迟、下载 100 KiB/s、上传 50 KiB/s；切换即时反馈并保留旧内容，周期 `/user` 不串行阻塞 |
| 跨页面导航 | 1000 ms 延迟、下载 100 KiB/s、上传 50 KiB/s；日历、网盘、时间线冷入与热访，保留同一文档及阿罗娜未发送草稿 |
| 离线恢复 | 星图、日历、项目历史切换范围等待联网；恢复后取得真实新范围，无误报空列表 |
| 页面分块失败 | 实际阻断分块下载，验证同页重试、失败提示、用户确认刷新与草稿恢复 |
| Service Worker | 本地真实构建 Worker 与公开静态资源响应；安装阶段无预下载，按需请求后产生缓存命中，API、私人图片和页面 HTML 不进入 Cache Storage |
| 工具模块与回执 | PC／手机中英文选择与服务器模板持久化；真实 API 写入后的回执驱动页面局部更新，保留编辑草稿及真实 409 冲突 |

网络缓存证据使用 CDP 或真实 Worker 请求，不以 `page.route` 的拦截结果声称 HTTP 缓存命中。部分回执用例只脚本化模型回答，实际业务写入仍经过隔离的真实 API；它们验证 UI 同步，服务端工具权限由独立真实 HTTP 回归验证。

测试日志、带宽条件及截图保存在部署者私有工作目录，避免把私人运行数据纳入源码。发布说明记录该次最终验收结果，不把本文件的测试方案视为未来版本已通过的证明。
