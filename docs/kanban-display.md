# 看板父任务提示

看板显示选项中的“显示上级任务”决定任务卡片是否展示上级关系提示。默认开启，关闭后收起卡片内的上级任务标签与路径，回收对应高度；分组模式也遵循该偏好。

这个选项只控制展示，不从看板筛除父任务卡片，不改任务数据或父子关系，不隐藏子任务完成进度，也不改变分组、排序、拖动或权限。需要查看关系时可以重新开启，或打开任务详情。

选择沿用已有看板显示偏好，按账户、API、项目与视图保存，受既有条目数量上限约束。旧偏好缺少该字段时保持开启。切换立即局部生效，无需刷新；重新进入同一看板继续使用已选偏好。

后续改动须验证普通卡片和分组模式、含子任务进度的父任务、重新加载的持久化、卡片高度实际减少，以及服务端关系保持不变。
