# 看板父任务提示

看板显示选项中的“显示上级任务”决定任务卡片是否展示上级关系提示。默认开启，关闭后收起卡片内的上级任务标签与路径，回收对应高度；分组模式也遵循该偏好。

这个选项只控制展示，不从看板筛除父任务卡片，不改任务数据或父子关系，不隐藏子任务完成进度，也不改变分组、排序、拖动或权限。需要查看关系时可以重新开启，或打开任务详情。

选择沿用已有看板显示偏好，按账户、API、项目与视图保存，受既有条目数量上限约束。旧偏好缺少该字段时保持开启。切换立即局部生效，无需刷新；重新进入同一看板继续使用已选偏好。

后续改动须验证普通卡片和分组模式、含子任务进度的父任务、重新加载的持久化、卡片高度实际减少，以及服务端关系保持不变。

## 手机阅读与跨列操作

手机看板继续使用列内纵向滚动和看板横向滚动，页面本身不横向溢出。顶部栏目导航提供上一栏、下一栏及原生栏目选择框，选择折叠列时先展开，只滚动看板；新增栏目也能从导航直接进入。320px 与 390px 下，栏目名与任务标题完整换行，不能只依赖鼠标悬浮才能读全。

普通卡片与分组行共用原生「移到其他列」选择框，可直接选择屏幕外的栏目，沿用完成列、日常任务及容量限制。移动成功才改变卡片位置，焦点跟随真实目标卡片；失败保留原状态。触屏卡片只在小拖动把手上开始长按拖动，卡片正文保持正常滚动、点按与链接行为，不再用透明整卡覆盖层抢占触摸。触摸操作目标至少 44px。只读共享保留栏目导航和完整阅读，不能出现编辑／移动／新增入口。

快速添加任务和栏目保留显式提交与取消按钮，离焦不关闭未提交内容，键盘 Enter 仍可提交。提交期间防止重复发送；完成回执只清除仍属于本次打开且未改写的文本，不覆盖后来输入或新打开的草稿。项目／视图切换沿用原有清理边界。
