# 具体的加载活动提示

慢请求持续约 1.2 秒后，页头下方的小浮层说明正在读取的资源。点击展开可查看每项阶段与耗时；折叠时保留最早活动与其余数量，关闭只隐藏提示，不取消请求。电脑和手机共用一份状态，原生对话框打开时浮层也可操作。

## 显示什么

- 首次读取且没有缓存的页面查询：项目、任务、栏目、日历、网盘、会话、星图条目、评论、账户用量等固定类别；必要时附数字 ID。可以显示等待服务器、重试、已等待多久。
- SDK Blob 文件读取：在响应体实际接收时显示已收字节；经过真实多块采样后显示近期接收速度。总大小可信时显示百分比和进度条。
- 没有可信总量时只显示已收字节，不估计百分比。传输停顿后停止显示旧速度，不能把等待服务器的耗时算成假进度。

名称不会直接拼入搜索词、资源标题、私人文件名、密钥、URL 或查询参数。固定类别与安全标识足以定位请求类别，不让悬浮通知泄露额外内容。

## 测量边界

字节数来自 Fetch 交付的响应体，不等同于网卡层流量。浏览器可能先解压数据，因此压缩响应的 Content-Length 不能作为解压后总量；跨域隐藏压缩头时也不显示百分比。缓存命中和单块完成的短文件可能没有足够采样，不伪造速度。

该提示覆盖共享查询层的首次读取和 SDK Blob 传输；不声称能逐字节跟踪浏览器原生 img、脚本分包、字体或 Service Worker 内部缓存。普通有缓存的后台轮询、阿罗娜 SSE 流和已有专门上传进度的写入不重复进入浮层。离线状态沿用原有离线提示。

## 生命周期与成本

活动按账户、API 和登录会话隔离。切换身份、API、退出登录、取消、错误和完成时清理对应任务；同一身份正常刷新 JWT 不会误判为换人。下载处理保留认证响应边界，避免旧响应回填新账户。

流体在原有 Blob 读取路径中采样，不额外 clone 整份二进制文件。进度更新节流，计时器只在存在任务时工作；展开最多渲染少量明细并说明剩余数量。背景读取支持 signal，消费者离开后可以取消。

新增资源查询时，应在中央分类中指定准确安全的类别；不能让未知查询键被原样展示。修改网络管道需验证成功、未知总量、压缩、停顿、早期失败、取消、身份／API 改变、正常 JWT 刷新以及真实 QueryClient 生命周期。
